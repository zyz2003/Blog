## Tasks

### 2. Album CRUD integration test

Test the full album lifecycle:

1. **Create album category** — POST /api/album-categories
   - Request: `{ name: "风景", description: "风景照片", displayOrder: 1 }`
   - Verify: response.data has id, name, description, displayOrder

2. **List categories** — GET /api/album-categories
   - Verify: returns array with created category

3. **Create album** — POST /api/albums/add
   - Request: `{ imageUrl: "https://example.com/photo.jpg", fileHash: "abc123", categoryId: 1, tags: ["风景", "自然"], width: 1920, height: 1080 }`
   - Verify: success message, album created with aspectRatio "16:9"

4. **Create duplicate album** — POST /api/albums/add
   - Same fileHash → verify error "这张图片已存在"

5. **Get albums** — GET /api/albums/get?page=1&pageSize=10
   - Verify: { list, total, pageNum, pageSize } format
   - Verify: album in list has widthAndHeight "1920x1080"

6. **Update album** — PUT /api/albums/update/1
   - Request: `{ imageUrl: "https://example.com/photo2.jpg", title: "Updated Title" }`
   - Verify: success message

7. **Batch delete albums** — DELETE /api/albums/batch-delete
   - Request: `{ ids: [1] }`
   - Verify: { deleted: 1 }

8. **Soft-delete + CreateOrRestore restore path** — Critical test:
   - Create album A with fileHash "hash1" → success
   - Delete album A (soft delete) → success
   - Verify: GET /api/albums/get does NOT include album A (soft-deleted, filtered by deletedAt IS NULL)
   - Create album B with same fileHash "hash1" → should SUCCEED with "restored" status (restore the soft-deleted record)
   - Verify: GET /api/albums/get now includes the restored album

9. **Delete category** — DELETE /api/album-categories/1
   - If **active** albums still reference it → verify error "该分类下还有相册，无法删除"
   - Soft-deleted albums referencing it should NOT block the deletion
   - After removing all active album references → verify success

### 8. API compatibility spot-check

Compare key response shapes with Go backend:

- Album list response: `{ list: AlbumResponse[], total, pageNum, pageSize }`
- AlbumResponse: integer id, computed widthAndHeight, all camelCase fields
- AlbumCategoryDTO: integer id, name, description, displayOrder
- DocSeriesResponse: Sqids string id, snake_case created_at/updated_at/cover_url/doc_count
- DocSeriesListResponse: `{ list, total, page, pageSize }`
- DocSeriesWithArticles: DocSeriesResponse + articles array
- DocArticleItem: Sqids string id, title, abbrlink, doc_sort, created_at
