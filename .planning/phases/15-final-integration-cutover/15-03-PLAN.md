    **1. Prerequisites:**
    - Node.js v22+ (verified with node --version)

    **2. Quick Start:**
    - Install dependencies: `npm install` in both server/ and frontend/ directories (or use project root if workspaces configured)
    - Start backend: `cd server && npm run dev` — starts on port 8091
    - Start frontend: `cd frontend && npm run dev` — starts on port 3000, proxies /api/* to localhost:8091
    - Open http://localhost:3000 in browser

    **3. Database:**
    - SQLite database auto-created at server/data/anheyu.db on first startup
    - WAL mode enabled for concurrent reads, busy_timeout=5000 for write conflicts
    - 334 default settings auto-seeded from Go definition.go on first startup
    - Default admin user: email=admin@test.com, password=password123 (if seeded)

    **4. Environment Variables:**
    - No .env file required for local development
    - JWT_SECRET: auto-generated and stored in database settings table on first startup (not in .env)
    - PORT: defaults to 8091, configurable via PORT env var
    - DB_PATH: defaults to data/anheyu.db, configurable via DB_PATH env var

    **5. Data Migration (from Go backend):**
    - Migration tool: scripts/migrate.ts
    - Prerequisites: existing Go backend SQLite database file
    - Run migration: `cd server && npm run migrate -- --source /path/to/go-backend.db --target ./data/anheyu.db`
    - Dry run (preview): `cd server && npm run migrate:dry-run -- --source /path/to/go-backend.db --target ./data/anheyu.db`
    - Options: --skip-backup, --skip-verify, --verbose
    - The tool handles: FK dependency ordering, timestamp conversion, table/column name mapping, post-migration verification
    - Not mandatory per project constraint — can start from empty database

    **6. Build for Production:**
    - Build backend: `cd server && npm run build`
    - Start production: `cd server && npm run start:prod`
    - Build frontend: `cd frontend && npm run build`
    - Start frontend: `cd frontend && npm start`
