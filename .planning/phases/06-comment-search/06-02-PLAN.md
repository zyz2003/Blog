  <action>
Create SearchService as an @Injectable() provider. Inject DRIZZLE token and SettingsService.

FTS5 Table Management:
- ensureFts5Table(): Execute raw SQL to CREATE VIRTUAL TABLE IF NOT EXISTS articles_fts USING fts5(title, content, keywords, content='', tokenize='unicode61 tokens 0'). This must run on module initialization (OnModuleInit). Also DROP existing table data before rebuild to ensure clean state.
- rebuildAllIndexes(): Query all published articles (status='PUBLISHED', deletedAt null) from articles table. For each article, strip HTML from contentHtml using regex replace, then INSERT INTO articles_fts(rowid, title, content, keywords) VALUES (article.id, article.title, strippedContent, article.keywords || ''). Called from ensureFts5Table after table creation.

Index Operations:
- indexArticle(article: { id, title, contentHtml, keywords }): Strip HTML from contentHtml, INSERT INTO articles_fts(rowid, title, content, keywords). Per D-151.
- deleteArticle(articleDbId: number): DELETE FROM articles_fts WHERE rowid = articleDbId. Per D-151.

Search:
- search(query: string, page: number, size: number): Execute FTS5 MATCH query with bm25(articles_fts, 10.0, 1.0, 5.0) ranking per D-147. SELECT rowid as id, bm25(articles_fts, 10.0, 1.0, 5.0) AS rank FROM articles_fts WHERE articles_fts MATCH ? ORDER BY rank LIMIT ? OFFSET ?. Then join results back to articles table to get full article data (title, contentHtml, coverUrl, abbrlink, viewCount, wordCount, readingTime, isDoc, docSeriesId, keywords, ownerId). Build SearchHit objects with all fields from Go model.SearchHit. Apply normalizeSearchHits to fill type and url. Return SearchResult with pagination.

Snippet Extraction (per D-152):
- extractSnippet(contentHtml: string, maxLength=150): Strip HTML tags using regex, trim whitespace, handle Unicode properly using [...plainText] spread for rune-level slicing, append "..." if truncated. Matches Go SimpleSearcher articleToSearchHit snippet logic.

normalizeSearchHits (per Go search_service.go lines 86-109):
- For each hit: if type is already set, skip. If isDoc=true, set type="doc" and url="/doc/{id}" (id is Sqids public ID). Otherwise type="post" and url="/posts/{abbrlink}" (fallback to id if abbrlink empty).

SearchHit construction:
- id: Sqids public ID (generatePublicID(article.id, EntityType.Article))
- type: filled by normalizeSearchHits
- url: filled by normalizeSearchHits
- title: article.title
- snippet: extractSnippet(article.contentHtml)
- author: article.copyrightAuthor || settingsService.Get('front_desk.site_owner_name')
- category: first postCategory name from article relations (query with relations)
- tags: array of postTag names from article relations
- publish_date: article.createdAt as ISO string
- cover_url: article.coverUrl
- abbrlink: article.abbrlink
- view_count: article.viewCount
- word_count: article.wordCount
- reading_time: article.readingTime
- is_doc: article.isDoc
- doc_series_id: Sqids encoded if article.docSeriesId exists

For the search query, join FTS5 results with articles table to get full article data including relations (categories, tags). Use Drizzle for the article query part and raw SQL for the FTS5 part. The FTS5 query returns rowids, then use those rowids to fetch full article records with Drizzle including postCategories and postTags relations.
