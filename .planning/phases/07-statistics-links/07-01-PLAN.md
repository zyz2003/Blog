Create StatisticsRepository as an @Injectable() provider. Inject DRIZZLE token from DatabaseModule. Implement the following methods using Drizzle query builder and sql template tag per D-167 (mixed mode: complex aggregations use raw SQL, simple queries use Drizzle builder):

1. createLog(params: { visitorId, sessionId?, ipAddress, userAgent?, referer?, urlPath, country?, region?, city?, browser?, os?, device?, duration, isBounce }): Insert into visitor_logs table. Returns inserted record.

2. countTotalViews(date: Date): Count rows in visitor_logs where createdAt falls within the given date (China timezone day boundary). Uses sql template: SELECT COUNT(*) as count FROM visitor_logs WHERE created_at >= ? AND created_at < ?. Returns number.

3. countUniqueVisitors(date: Date): Count distinct visitorId in visitor_logs for the given date. Uses sql template: SELECT COUNT(DISTINCT visitor_id) as count FROM visitor_logs WHERE created_at >= ? AND created_at < ?. Returns number.

4. getVisitorStatsByDate(date: Date): Query visitor_stats where date matches. Returns row or undefined.

5. getVisitorStatsByDateRange(startDate: Date, endDate: Date): Query visitor_stats where date is between startDate and endDate. Returns array of rows. Used for month/year aggregation (SUM of uniqueVisitors/totalViews/pageViews/bounceCount).

6. upsertVisitorStats(date: Date, isUnique: boolean, isBounce: boolean): Try to get existing visitor_stats row for date. If exists, increment: totalViews+1, uniqueVisitors+(isUnique?1:0), pageViews+1, bounceCount+(isBounce?1:0). If not exists, insert new row with initial values. Uses Drizzle sql template for atomic increment.

7. incrementUrlStats(urlPath: string, isUnique: boolean, duration: number, isBounce: boolean): Try to get existing url_stats row by urlPath. If exists, update: totalViews+1, uniqueViews+(isUnique?1:0), bounceCount+(isBounce?1:0), recalculate avgDuration as weighted average, set lastVisitedAt=now. If not exists, insert new row. Uses Drizzle sql template for atomic operations.

8. getTopPages(limit: number): Query url_stats ORDER BY total_views DESC LIMIT limit. Returns array of url_stats rows. Uses Drizzle query builder (simple query per D-167).

9. getVisitorAnalytics(startDate: Date, endDate: Date): Execute 6 GROUP BY queries on visitor_logs for the date range, each returning top N results per dimension. Uses sql template tag for raw SQL per D-167:
   - top_browsers: SELECT browser as name, COUNT(*) as count FROM visitor_logs WHERE created_at >= ? AND created_at < ? AND browser IS NOT NULL AND browser != '' GROUP BY browser ORDER BY count DESC LIMIT 10
   - top_os: same pattern with os field
   - top_devices: same pattern with device field
   - top_cities: same pattern with city field
   - top_countries: same pattern with country field
   - top_referers: same pattern with referer field
   Returns object with all 6 arrays.

10. getVisitorLogsByTimeRange(startDate: Date, endDate: Date, page: number, pageSize: number): Query visitor_logs with date range filter, paginated with offset/limit. Returns { list, total }. Uses Drizzle query builder.

All date parameters use China timezone (UTC+8) for day boundaries. Use the pattern from Go backend: start of day = date at 00:00:00+08:00, end of day = date at 23:59:59+08:00. Convert to Unix timestamps for SQLite integer comparison.

Follow the pattern from CommentRepository for Drizzle query construction. Use eq(), and(), isNull(), gte(), lte(), desc(), sql from drizzle-orm.

VisitorLogsQueryDto (GET /statistics/visitor-logs): start_date (@IsOptional, @IsString), end_date (@IsOptional, @IsString), page (@IsOptional, @IsInt, @Min(1), default 1), page_size (@IsOptional, @IsInt, @Min(1), @Max(200), default 20).

VisitorStatisticsDto (GET /public/statistics/basic): today_visitors (number), today_views (number), yesterday_visitors (number), yesterday_views (number), month_views (number), year_views (number). Matches Go VisitorStatistics struct exactly.

VisitorAnalyticsDto (GET /statistics/analytics): top_countries (array of {country, count}), top_cities (array of {city, count}), top_browsers (array of {browser, count}), top_os (array of {os, count}), top_devices (array of {device, count}), top_referers (array of {referer, count}). UrlStatisticsDto (GET /statistics/top-pages): url_path (string), page_title (string|null), total_views (number), unique_views (number), bounce_count (number), bounce_rate (number), avg_duration (number), last_visited_at (string|null). Matches Go URLStatistics struct. bounce_rate = bounce_count/total_views (0 if totalViews=0).

VisitorTrendDataDto (GET /statistics/trend): daily (array of {date, visitors, views}), weekly (empty array per Go backend), monthly (empty array per Go backend). Matches Go VisitorTrendData.

**UA Parser Utility (ua-parser.ts):**

Create UAParserService as @Injectable(). Uses ua-parser-js per D-165. Private cache Map with MD5-keyed entries and 12h TTL (matching Go userAgentCache). Method parse(userAgent: string): { browser: string, os: string, device: string }. Cache key = MD5 hex of userAgent string. On cache miss, call UAParser(userAgent) and extract browser.name, os.name, device.type. Default device to 'Desktop' if type is undefined. Store result with timestamp. Cleanup: setInterval every 30 minutes to purge entries older than 12h (matching Go cleanupCaches pattern).

**Visitor Dedup Utility (visitor-dedup.ts):**

Create VisitorDedupService as @Injectable() per D-161. Three Maps:
1. uvDedupMap: key format stat:uv:{ip}:{date} (unique visitor dedup), TTL to end of current day in China timezone
2. pvDedupMap: key format stat:pv:{ip}:{urlPath}:{date} (unique page view dedup), TTL to end of current day
3. requestDedupMap: key format {visitorId}:{urlPath}:{timestamp/3s} (3-second request dedup), TTL 3 seconds

Methods:
- isUniqueVisitor(ip: string, date: string): boolean — checks/sets uvDedupMap, returns true if new visitor
- isUniquePageView(ip: string, urlPath: string, date: string): boolean — checks/sets pvDedupMap
- isDuplicateRequest(visitorId: string, urlPath: string): boolean — checks/sets requestDedupMap with 3s window
- cleanup(): iterate all maps, delete expired entries. Called by setInterval every 30 minutes.

Each Map entry stores { value: true, expiresAt: number (ms timestamp) }. On check, if entry exists and expiresAt > Date.now(), return false (not unique). If expired or missing, set new entry and return true.

**Extend error-codes.ts:** Add STAT_INVALID_DATE ('日期格式错误'), STAT_VISIT_RECORD_FAILED ('记录访问失败').
