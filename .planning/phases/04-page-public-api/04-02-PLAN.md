Output: version.module.ts, version.controller.ts

    Apply @Public() at class level and @Controller('version') decorator. Import Public from common/decorators/public.decorator, Controller/Get/Res/Header from @nestjs/common, Response from express.

    Implement getVersion method with @Get() and @Header decorators for no-cache per D-91:
    - @Header('Cache-Control', 'no-cache, no-store, must-revalidate, private, max-age=0')
    - @Header('Pragma', 'no-cache')
    - @Header('Expires', '0')
    - Return object with data property containing BuildInfo: { version: getVersionValue(), commit: getCommitValue(), date: getDateValue(), node_version: process.version } and message property '获取版本信息成功'. The global interceptor will wrap this as { code: 200, data: { version, commit, date, node_version }, message: '获取版本信息成功' } per D-88. Note: the controller returns { data: buildInfo, message: '...' } and the interceptor picks up data and message from the return value, adding code: 200. Verify the interceptor behavior by reading server/src/common/interceptors/response.interceptor.ts.

    Implement getVersionString method with @Get('string') and @Res() decorator per D-89:
    - Access raw Response object via @Res() res: Response parameter
    - Set no-cache headers directly on res: setHeader('Cache-Control', ...), setHeader('Pragma', ...), setHeader('Expires', ...)
    - Build version string: start with version value, if commit not 'unknown' append ', commit {commit}', if date not 'unknown' append ', built at {date}'
    - Call res.json({ version: versionString }) to bypass global interceptor per D-89

    Implement private helper methods:
    - getVersionValue(): return process.env.VERSION || 'dev' per D-90
    - getCommitValue(): return process.env.COMMIT || 'unknown' per D-90
    - getDateValue(): return process.env.BUILD_DATE || 'unknown' per D-90

    Create server/src/version/version.module.ts:
    - Import Module from @nestjs/common
    - Import VersionController
    - @Module({ controllers: [VersionController] }) per D-93 (no providers, no imports — no service dependency)
    - Export VersionModule

    Key detail: The getVersion method returns data that the global interceptor wraps. The getVersionString method uses @Res() which completely bypasses the interceptor. This matches Go's GetVersion (uses response.Success/c.JSON with code+data+message) vs GetVersionString (uses c.JSON directly with just { version }).
