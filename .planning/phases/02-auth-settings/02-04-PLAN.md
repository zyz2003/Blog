    - Test 5: verify(image_captcha_id, image_captcha_answer) succeeds case-insensitively and deletes cache entry

  <action>
    Per D-34, D-37:

    Install dependencies: npm install svg-captcha @nestjs/throttler

    Create ImageCaptchaService (injectable):
    - Constructor injects MemoryCache (from CommonModule)
    - generate(length: number = 4): { captchaId: string, imageBase64: string }
      - Generate UUID v4 using crypto.randomUUID() for captchaId
      - Use svg-captcha.create() with config: size=length, noise=2, color=true, background="#f5f5f5", width=240, height=80, charPreset="23456789abcdefghjkmnpqrstuvwxyzABCDEFGHJKMNPQRSTUVWXYZ" (exclude confusing chars 0/O/1/l/I)
      - Store answer as lowercase in MemoryCache: cache.set(captchaId, answer.toLowerCase(), ttl) where ttl comes from SettingsService.get('image_captcha.expire') parsed as number * 1000 (convert seconds to ms), default 300000 (5 minutes)
      - Return { captchaId, imageBase64: "data:image/svg+xml;base64," + Buffer.from(svgCaptcha.data).toString('base64') }

    Create CaptchaService (injectable):
    - Constructor injects SettingsService, ImageCaptchaService
    - getConfig(): { provider: string, image_captcha_length?: number }
      - Read captcha.provider from SettingsService.get('captcha.provider'), default "none"
      - If provider === "image": add image_captcha_length from SettingsService.get('captcha.image_captcha_length') parsed as int, default 4
      - Return config object
    - generateImage(): { captcha_id: string, image_base64: string }
      - Read image_captcha_length from settings, default 4
      - Call imageCaptchaService.generate(length)
      - Return { captcha_id: result.captchaId, image_base64: result.imageBase64 }
    - verify(captchaParams: { image_captcha_id?: string, image_captcha_answer?: string }): boolean
      - Read provider from settings
      - If provider === "none": return true (skip verification)
      - If provider === "image":
        - If no image_captcha_id or image_captcha_answer: throw BadRequestException("验证码参数缺失")
        - Get cached answer from MemoryCache
        - If not found: throw BadRequestException("验证码已过期")
        - Compare case-insensitively: cachedAnswer === answer.toLowerCase()
        - Delete cache entry after verification (one-time use)
        - If mismatch: throw BadRequestException("验证码错误")
        - Return true
      - For other providers (turnstile, geetest): return true (deferred per D-34)

    Create CaptchaModule:
    - imports: CommonModule (for MemoryCache), SettingsModule (global)
    - providers: [CaptchaService, ImageCaptchaService]
    - exports: [CaptchaService]
    - controllers: [CaptchaController] (added in Task 2)
