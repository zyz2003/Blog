<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin -> POST /api/ai/generate-summary/:id | Authenticated admin triggers LLM call; input is article publicId |
| Backend -> LLM API (external) | Server sends API key + article content to external LLM service |
| Settings DB -> resolveProfiles | Reading configuration from database (trusted source) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-01 | Information Disclosure | summary.adapter.ts error handling | medium | mitigate | Catch LLM errors, return generic messages — never expose API keys or LLM response details in error messages |
| T-16-02 | Tampering | summary.adapter.ts article content | medium | accept | htmlToPlainText strips HTML; 4000 char truncation limits prompt injection surface — acceptable for admin-only feature |
| T-16-03 | Information Disclosure | ai_profiles API keys in settings | high | mitigate | ai_profiles and ai_summary_api_key are NOT in PUBLIC_SETTING_KEYS (verified in public-setting-keys.ts) — non-admin cannot read |
| T-16-04 | Denial of Service | POST /api/ai/generate-summary/:id | medium | mitigate | JwtAuthGuard + AdminGuard restrict to admin only; AI SDK timeout: { totalMs: 30000 } prevents hanging |
| T-16-SC | Tampering | npm install ai + @ai-sdk/openai-compatible + zod | high | mitigate | SUS packages from Vercel AI SDK monorepo — pin exact versions, verify postinstall scripts absent |
</threat_model>
