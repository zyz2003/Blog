Create CommentController (public endpoints, matching Go commentsPublic route group from router.go lines 258-272):

@Controller('public/comments') with @Public() class decorator.

Methods:
1. @Get() listByPath(@Query('target_path') targetPath: string, @Query('page') page?: number, @Query('pageSize') pageSize?: number): Call commentService.listByPath(targetPath, page||1, pageSize||10). Return ListCommentResponseDto.

2. @Get('latest') listLatest(@Query('page') page?: number, @Query('pageSize') pageSize?: number): Call commentService.listLatest(page||1, pageSize||10). Return ListCommentResponseDto.

3. @Get(':id/children') listChildren(@Param('id') id: string, @Query('page') page?: number, @Query('pageSize') pageSize?: number): Call commentService.listChildren(id, page||1, pageSize||3). Default pageSize=3 for preview mode matching Go behavior.

4. @Post() @UseGuards(JwtAuthOptionalGuard) create(@Body() dto: CreateCommentDto, @Req() req: any): Extract ip from req.ip || req.connection?.remoteAddress, ua from req.headers['user-agent'], referer from req.headers['referer']. Extract claims from req.user (set by JwtAuthOptionalGuard if JWT present). Call commentService.create(dto, ip, ua, referer, claims). Return CommentResponseDto.

5. @Post('upload') @UseGuards(JwtAuthOptionalGuard) @UseInterceptors(FileInterceptor('file')) uploadImage(@UploadedFile() file: Express.Multer.File, @CurrentUser() user: any): Call commentService.uploadImage(file, user). Return { id: string }. Per D-141, D-142.

6. @Post(':id/like') like(@Param('id') id: string): Call commentService.likeComment(id). Return { like_count: number }.

7. @Post(':id/unlike') unlike(@Param('id') id: string): Call commentService.unlikeComment(id). Return { like_count: number }.

IMPORTANT: Route ordering — listLatest must be declared BEFORE listByPath's generic @Get() to avoid 'latest' being captured as :id param. Same pattern as Go router where specific routes are registered before parametric ones. Alternatively, use @Get('latest') before @Get() in the class.

Create CommentAdminController (admin endpoints, matching Go commentsAdmin route group from router.go lines 279-288):

@Controller('comments') with @UseGuards(AdminGuard) class decorator. No @Public() — these require JWT + Admin.

Methods:
1. @Get() adminList(@Query() dto: AdminListCommentDto): Call commentService.adminList(dto). Return ListCommentResponseDto with isAdminView=true.

2. @Delete() delete(@Body() dto: DeleteCommentDto): Call commentService.delete(dto.ids). Return null.

3. @Put(':id') updateContent(@Param('id') id: string, @Body() dto: UpdateContentCommentDto): Call commentService.updateContent(id, dto.content). Return CommentResponseDto.

4. @Put(':id/info') updateCommentInfo(@Param('id') id: string, @Body() dto: UpdateCommentInfoDto): Call commentService.updateCommentInfo(id, dto). Return CommentResponseDto.

5. @Put(':id/status') updateStatus(@Param('id') id: string, @Body() dto: UpdateStatusCommentDto): Call commentService.updateStatus(id, dto.status). Return CommentResponseDto.

6. @Put(':id/pin') setPin(@Param('id') id: string, @Body() dto: SetPinCommentDto): Call commentService.setPin(id, dto.pinned). Return CommentResponseDto.

For IP extraction in create method, handle proxy headers: check req.headers['x-forwarded-for'] first, then fall back to req.ip, then req.connection?.remoteAddress. This matches typical NestJS IP extraction pattern and handles reverse proxy scenarios.
