## Tasks

### 1. Create AlbumService

Create `server/src/album/album.service.ts`:

```typescript
@Injectable()
export class AlbumService {
  constructor(
    private readonly albumRepo: AlbumRepository,
    private readonly albumCategoryRepo: AlbumCategoryRepository,
    private readonly settingsService: SettingsService,
    private readonly thumbnailService: ThumbnailService,
    private readonly postTagService: PostTagService,
  ) {}
```

Methods matching Go `pkg/service/album/service.go`:

**createAlbum(params: CreateAlbumParams)** — Core CreateOrRestore logic:
1. Compute effectiveFileHash: if fileHash non-empty use it; else SHA256(imageUrl)
2. Build album model with all params
3. Compute aspectRatio via getSimplifiedAspectRatioString(width, height)
4. Join tags array to comma-separated string
5. applyDefaultAlbumParams(album)
6. Call albumRepo.createOrRestore(album)
7. On status 'created' or 'restored': Call `postTagService.findOrCreate(params.Tags)` to ensure tags exist in the post_tags table (matching Go's `s.tagRepo.FindOrCreate(ctx, params.Tags)`). This is needed for the tag filtering feature on album queries. Log error but don't fail if tag creation fails (matching Go behavior: `fmt.Printf("处理新图片标签时发生错误: %v\n", err)`). **Note:** `PostTagService` currently lacks a `findOrCreate` method — add one that: for each tag name, check if it exists via `findByName`, if not create it. Use ON CONFLICT DO NOTHING for atomicity (matching Go's bulk create pattern).
8. On status 'existed': throw error "这张图片已存在，id是X，请勿重复添加"
9. Apply defaults again on final result
10. Return final album

**deleteAlbum(id: number)** — Call albumRepo.delete(id)

**batchDeleteAlbums(ids: number[])** — Call albumRepo.batchDelete(ids), return deleted count

**updateAlbum(id: number, params: UpdateAlbumParams)** — 
1. Find album by id → error if not found
2. Update fields from params
3. Join tags to comma-separated string
4. Call albumRepo.update(album)
5. Apply defaults on result
6. Return updated album

**findAlbums(params: FindAlbumsParams)** — 
1. Call albumRepo.findListByOptions with filters
2. Apply defaults on each item in result
3. Return paginated result

**incrementAlbumStat(id: number, statType: string)** —
1. If statType === 'view' → albumRepo.incrementViewCount(id)
2. If statType === 'download' → albumRepo.incrementDownloadCount(id)
3. Else → throw error "无效的统计类型"

**batchImportAlbums(params: BatchImportParams)** —
1. Pre-load all existing fileHashes for dedup
2. For each URL (index i):
   a. displayOrder = params.displayOrder + i
   b. fetchImageMetadata(url): HTTP GET with 60s timeout, decode image dimensions, compute SHA256 hash, determine format
   c. Check existingHashesMap → skip if duplicate
   d. Call createAlbum with imageUrl=bigImageUrl=downloadUrl=url
   e. After successful creation, call thumbnailService to generate thumbnail for the image URL
   f. Track success/fail/skip counts
3. Return BatchImportResult

**fetchImageMetadata(url: string)** — Private helper:
1. HTTP GET with User-Agent header, 60s timeout
2. Read response body
3. Use image-size or sharp to get dimensions (width, height)
4. Compute SHA256 hash of body
5. Determine format from response or URL extension
6. Return { width, height, fileSize, format, fileHash }

**exportAlbums(albumIds: number[])** —
1. If no albumIds → query all albums
2. Build ExportAlbumData: { version: "1.0", export_at, albums: [], meta }
3. For each albumId: find album, build ExportAlbumItem with snake_case keys
4. Return ExportAlbumData

**exportAlbumsToZip(albumIds: number[])** —
1. Call exportAlbums to get JSON data
2. Create ZIP buffer with albums.json + README.md
3. Return ZIP buffer

**importAlbumsFromJSON(jsonData: Buffer, req: ImportAlbumRequest)** —
1. Parse JSON as ExportAlbumData
2. Call importAlbums(data, req)

**importAlbums(data: ExportAlbumData, req: ImportAlbumRequest)** —
1. Pre-load existing categories for FK validation
2. Pre-load existing hashes for dedup (using effectiveAlbumFileHash)
3. For each album in data.albums:
   a. Check dedup via effectiveAlbumFileHash → skip if exists
   b. Validate categoryId → fallback to defaultCategoryId or null
   c. Parse tags from comma-separated string
   d. Call createAlbum
   e. Track success/skip/fail counts
4. Return ImportAlbumResult

**importAlbumsFromZip(zipData: Buffer, req: ImportAlbumRequest)** —
1. Extract albums.json from ZIP
2. Call importAlbumsFromJSON

**applyDefaultAlbumParams(album)** — Private helper matching Go:
1. If bigImageUrl empty → bigImageUrl = imageUrl
2. If downloadUrl empty → downloadUrl = imageUrl
3. If thumbParam empty → read from settings: `settingsService.get('DEFAULT_THUMB_PARAM')`
4. If bigParam empty → read from settings: `settingsService.get('DEFAULT_BIG_PARAM')`

**getSimplifiedAspectRatioString(width: number, height: number)** — Private helper:
1. If width <= 0 or height <= 0 → return "0:0"
2. Compute gcd(width, height)
3. Return `${width/gcd}:${height/gcd}`

**gcd(a: number, b: number)** — Private helper for greatest common divisor

**effectiveAlbumFileHash(fileHash: string, imageUrl: string)** — Private helper:
1. If fileHash non-empty after trim → return fileHash
2. If imageUrl non-empty after trim → return SHA256(imageUrl) as hex
3. Else return empty string

**toResponseDTO(album)** — Convert DB record to AlbumResponse:
- Map all fields
- Compute widthAndHeight as `${width}x${height}`
- Apply read-time defaults matching Go's `toDomainAlbum`:
  - bigImageUrl = album.bigImageUrl || album.imageUrl (if bigImageUrl is empty in DB, use imageUrl)
  - downloadUrl = album.downloadUrl || album.imageUrl (if downloadUrl is empty in DB, use imageUrl)
