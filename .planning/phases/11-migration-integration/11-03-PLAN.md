## Objective

Create API compatibility test files for content modules (post categories, post tags, comments, search, doc series, article history) and file/media modules (files, storage policies, thumbnails, direct links).

**Endpoints covered:**

- GET /api/post-categories — List (public)
- POST /api/post-categories — Create (JWT+Admin)
- PUT /api/post-categories/:id — Update (JWT+Admin)
- DELETE /api/post-categories/:id — Delete (JWT+Admin)

Post Tag (4):
- GET /api/post-tags — List (JWTOptional)
- POST /api/post-tags — Create (JWT+Admin)
- PUT /api/post-tags/:id — Update (JWT+Admin)
- DELETE /api/post-tags/:id — Delete (JWT+Admin)

Comment (16):
- GET /api/public/comments — List by path
- GET /api/public/comments/latest — Latest comments
- GET /api/public/comments/:id/children — Nested children
- GET /api/public/comments/qq-info — QQ info lookup
- GET /api/public/comments/ip-location — IP location
- POST /api/public/comments — Create (JWTOptional)
- POST /api/public/comments/upload — Upload image (JWTOptional, multipart)
- POST /api/public/comments/:id/like — Like
- POST /api/public/comments/:id/unlike — Unlike
- GET /api/comments — Admin list (JWT+Admin)
- DELETE /api/comments — Admin delete (JWT+Admin)
- PUT /api/comments/:id — Update content (JWT+Admin)
- PUT /api/comments/:id/info — Update info (JWT+Admin)
- PUT /api/comments/:id/status — Update status (JWT+Admin)
- PUT /api/comments/:id/pin — Pin (JWT+Admin)
- POST /api/comments/export — Export (JWT+Admin)
- POST /api/comments/import — Import (JWT+Admin)

Search (1):
- GET /api/search?q=... — Search articles

Doc Series (8):
- GET /api/public/doc-series — Public list
- GET /api/public/doc-series/:id — Public detail
- GET /api/public/doc-series/:id/articles — With articles
- GET /api/doc-series — Admin list (JWT+Admin)
- GET /api/doc-series/:id — Admin detail (JWT+Admin)
- POST /api/doc-series — Create (JWT+Admin)
- PUT /api/doc-series/:id — Update (JWT+Admin)
- DELETE /api/doc-series/:id — Delete (JWT+Admin)

Article History (5):
- GET /api/articles/:id/history — List history (JWT)
- GET /api/articles/:id/history/count — History count (JWT)
- GET /api/articles/:id/history/compare — Compare versions (JWT)
- GET /api/articles/:id/history/:version — Get version (JWT)
- POST /api/articles/:id/history/:version/restore — Restore version (JWT)

**Key assertions:**
- Post categories/tags: list is array of { id, name, sort/articleCount }
- Comments: nested structure with parent/children, like/unlike toggle, admin moderation
- Search: results have { list, total } with article items
- Doc series: has articles array, doc_count field, Sqids string id
- Article history: list of versions with version number and timestamp

### Task 2: File & media module test files (4 files)

**Files:**
- `server/test/api-compat/file-api-compat.spec.ts`
- `server/test/api-compat/storage-policy-api-compat.spec.ts`
- `server/test/api-compat/thumbnail-api-compat.spec.ts`
- `server/test/api-compat/direct-link-api-compat.spec.ts`

**Endpoints covered:**

File (19):
- GET /api/file/content — Serve signed content
- GET /api/file — List files (JWT)
- GET /api/file/:id — File info (JWT)
- GET /api/file/download/:id — Download (JWT)
- GET /api/file/download-info/:id — Download info (JWT)
- POST /api/file/create — Create empty file (JWT)
- PUT /api/file/content/:publicID — Update content (JWT)
- DELETE /api/file — Delete items (JWT)
- PUT /api/file/rename — Rename (JWT)
- GET /api/file/preview-urls — Preview URLs (JWT)
- PUT /api/file/upload — Create upload session (JWT)
- GET /api/file/upload/session/:sessionId — Session status (JWT)
- POST /api/file/upload/:sessionId/:index — Upload chunk (JWT)
- POST /api/file/upload/finalize — Finalize upload (JWT)
- DELETE /api/file/upload — Delete session (JWT)
- PUT /api/folder/view — Update folder view (JWT)
- GET /api/folder/tree/:id — Folder tree (JWT)
- GET /api/folder/size/:id — Folder size (JWT)
- POST /api/folder/move — Move items (JWT)
- POST /api/folder/copy — Copy items (JWT)

Storage Policy (7):
- POST /api/policies — Create (JWT+Admin)
- GET /api/policies — List (JWT+Admin)
- GET /api/policies/connect/onedrive/:id — Connect OneDrive (JWT+Admin)
- POST /api/policies/authorize/onedrive — Authorize OneDrive (JWT+Admin)
- GET /api/policies/:id — Get (JWT+Admin)
- PUT /api/policies/:id — Update (JWT+Admin)
- DELETE /api/policies/:id — Delete (JWT+Admin)

Thumbnail (4):
- POST /api/thumbnail/regenerate — Regenerate (JWT)
- POST /api/thumbnail/regenerate/directory — Regenerate directory (JWT)
- GET /api/thumbnail/:publicID — Get sign (JWT)
- GET /api/t/:signedToken — Serve thumbnail content (public)

Direct Link (2):
- POST /api/direct-links — Get or create (JWT)
- GET /api/f/:publicID/*filename — Direct download (public)

**Key assertions:**
- File list has tree structure with children
- Upload session lifecycle (create → upload chunk → finalize) — uses multipart helper
- Storage policy has flag, max_size, type fields; only type='local' allowed
- Thumbnail returns signed URL or image content
- Direct link download has Content-Disposition header

**Verification:** `npx vitest run server/test/api-compat/file-api-compat.spec.ts server/test/api-compat/storage-policy-api-compat.spec.ts server/test/api-compat/thumbnail-api-compat.spec.ts server/test/api-compat/direct-link-api-compat.spec.ts --reporter=verbose`
