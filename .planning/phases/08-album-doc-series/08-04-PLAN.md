# Phase 08-04: Controllers + Module Wiring

**Phase:** 08 — Album & Doc Series
**Wave:** 3 (depends on 08-01, 08-02, 08-03)
**Depends on:** 08-01, 08-02, 08-03 complete

## Goal

Create all controllers (AlbumController, AlbumCategoryController, PublicAlbumController, DocSeriesController) and wire AlbumModule + DocSeriesModule.

## Tasks

### 1. Create AlbumController

Create `server/src/album/album.controller.ts`:

Admin endpoints (all with @UseGuards(JwtAuthGuard, AdminGuard)):

| Route | Method | Handler | Notes |
|-------|--------|---------|-------|
| /api/albums/get | GET | getAlbums | Query params: page, pageSize, categoryId, tag, createdAt[0], createdAt[1], sort |
| /api/albums/add | POST | addAlbum | Body: CreateAlbumRequestDto |
| /api/albums/batch-import | POST | batchImport | Body: BatchImportRequestDto |
| /api/albums/update/:id | PUT | updateAlbum | Param: id(int), Body: UpdateAlbumRequestDto |
| /api/albums/delete/:id | DELETE | deleteAlbum | Param: id(int) |
| /api/albums/batch-delete | DELETE | batchDeleteAlbums | Body: BatchDeleteRequestDto |
| /api/albums/export | POST | exportAlbums | Body: ExportAlbumsRequestDto — returns file download |
| /api/albums/import | POST | importAlbums | Multipart: file + form fields |

**Important route patterns from Go backend:**
- GET /api/albums/get (not just /api/albums)
- POST /api/albums/add (not just /api/albums)
- PUT /api/albums/update/:id (not /api/albums/:id)
- DELETE /api/albums/delete/:id (not /api/albums/:id)
- DELETE /api/albums/batch-delete

**getAlbums handler:**
1. Parse query params via FindAlbumsQueryDto
2. Call albumService.findAlbums(params)
3. Map each album to AlbumResponse (include computed widthAndHeight)
4. Return { list, total, pageNum, pageSize }

**addAlbum handler:**
1. Parse body via CreateAlbumRequestDto
2. Call albumService.createAlbum(params)
3. Return null with message "添加成功"

**exportAlbums handler:**
1. Parse body via ExportAlbumsRequestDto
2. If format === 'zip': call albumService.exportAlbumsToZip → set download headers → return buffer
3. If format === 'json': call albumService.exportAlbums → set download headers → return JSON
4. Use @Res() decorator to bypass ResponseInterceptor for file downloads

**importAlbums handler:**
1. Use @UseInterceptors(FileInterceptor('file')) for multipart upload
2. Parse form fields: skip_existing, overwrite_existing, default_category_id
3. Determine format from file extension (.json or .zip)
4. Call albumService.importAlbumsFromJSON or importAlbumsFromZip
5. Return ImportAlbumResult

### 3. Create PublicAlbumController

Create `server/src/album/public-album.controller.ts`:

Public endpoints (with @Public() decorator, @UseGuards(JwtAuthOptionalGuard)):

| Route | Method | Handler |
|-------|--------|---------|
| /api/public/albums | GET | getPublicAlbums |
| /api/public/album-categories | GET | getPublicAlbumCategories |
| /api/public/stat/:id | PUT | updateAlbumStat |

**getPublicAlbums:**
1. Same as admin getAlbums but default pageSize=12 (not 10)
2. Call albumService.findAlbums(params)
3. Return { list, total, pageNum, pageSize }

**getPublicAlbumCategories:**
1. Call albumCategoryService.listCategories()
2. Return AlbumCategoryDTO[]

**updateAlbumStat:**
1. Parse param id (integer) and query type ("view" | "download")
2. Call albumService.incrementAlbumStat(id, type)
3. Return null with message "更新成功"

### 4. Create DocSeriesController

Create `server/src/doc-series/doc-series.controller.ts`:

This controller handles both admin and public endpoints (matching Go backend where same handler serves both):

**Public endpoints (with @Public() decorator):**

| Route | Method | Handler |
|-------|--------|---------|
| /api/public/doc-series | GET | list |
| /api/public/doc-series/:id | GET | get |
| /api/public/doc-series/:id/articles | GET | getWithArticles |

**Admin endpoints (with @UseGuards(JwtAuthGuard, AdminGuard)):**

| Route | Method | Handler |
|-------|--------|---------|
| /api/doc-series | GET | list |
| /api/doc-series/:id | GET | get |
| /api/doc-series | POST | create |
| /api/doc-series/:id | PUT | update |
| /api/doc-series/:id | DELETE | delete |

Note: Go backend uses the same List/Get handlers for both public and admin routes. The NestJS controller can use @Public() on specific method overloads or separate the routes.

**list:** Parse page/pageSize query, call docSeriesService.list(), return DocSeriesListResponse
**get:** Parse :id param (Sqids string), call docSeriesService.getById(id), return DocSeriesResponse
**getWithArticles:** Parse :id param, call docSeriesService.getByIdWithArticles(id), return DocSeriesWithArticles
**create:** Parse body via CreateDocSeriesRequestDto, call docSeriesService.create(req), return DocSeriesResponse
**update:** Parse :id param + body via UpdateDocSeriesRequestDto, call docSeriesService.update(id, req), return DocSeriesResponse
**delete:** Parse :id param, call docSeriesService.delete(id), return null with message "删除成功"
