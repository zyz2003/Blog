    - Test 2: findAllPublishedPaginated returns paginated published comments ordered by createdAt desc
    - Test 3: findById returns a single comment by DB ID
    - Test 4: findManyByIDs returns comments matching an array of DB IDs
    - Test 5: create inserts a comment and returns the created record
    - Test 6: adminList supports filters: nickname, email, targetPath, ipAddress, content, status with pagination
    - Test 7: softDelete sets deletedAt on comments matching given DB IDs
    - Test 8: updateStatus updates status field for a given DB ID
    - Test 9: updateContent updates content and contentHtml fields
    - Test 10: updateCommentInfo updates nickname, email, emailMd5, website fields
    - Test 11: setPin updates pinnedAt field (set to now or null)
    - Test 12: incrementLikeCount adds 1 to likeCount; decrementLikeCount subtracts 1 (min 0)
  </behavior>
  <action>
Create CommentRepository as an @Injectable() provider. Inject DRIZZLE token from DatabaseModule. Implement the following methods using Drizzle query builder against the `comments` table schema:

1. findAllPublishedByPath(targetPath: string): Query comments where targetPath matches, status=1 (Published), deletedAt is null. Limit results to 500. Order by createdAt desc. Returns array of comment rows.

2. findAllPublishedPaginated(page: number, pageSize: number): Query all published comments (status=1, deletedAt null) with offset/limit pagination. Returns { list, total }.

3. findById(dbId: number): Single comment by id where deletedAt is null. Returns comment or undefined.

4. findManyByIDs(dbIds: number[]): Batch query by id IN array. Returns array of comments.

5. create(params): Insert into comments table with all fields from CreateCommentParams (targetPath, targetTitle, userId, parentId, replyToId, nickname, email, emailMd5, website, content, contentHtml, status, isAdminComment, isAnonymous, userAgent, ipAddress, ipLocation). Returns inserted record.

6. adminList(filters: { page, pageSize, nickname?, email?, targetPath?, ipAddress?, content?, status? }): Build dynamic query with optional LIKE filters and exact status filter. Paginated. Returns { list, total }.

7. softDelete(dbIds: number[]): Update deletedAt=now where id IN dbIds.

8. updateStatus(dbId: number, status: number): Update status field.

9. updateContent(dbId: number, content: string, contentHtml: string): Update content and contentHtml fields, also set updatedAt=now.

10. updateCommentInfo(dbId: number, data: { nickname?, email?, emailMd5?, website? }): Update specified fields, set updatedAt=now.

11. setPin(dbId: number, isPinned: boolean): If isPinned=true, set pinnedAt=now. If false, set pinnedAt=null.

12. incrementLikeCount(dbId: number): Increment likeCount by 1. decrementLikeCount(dbId: number): Decrement by 1, minimum 0. Use sql`GREATEST(like_count - 1, 0)` for safe decrement.

Follow the pattern from ArticleRepository for Drizzle query construction. Use eq(), and(), isNull(), like(), sql, desc(), asc() from drizzle-orm. All queries must filter out soft-deleted records (deletedAt is null) except adminList which shows all non-deleted regardless of status.
