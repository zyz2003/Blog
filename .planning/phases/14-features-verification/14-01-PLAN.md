<objective>
Fix Link.id type mismatch (CRITICAL) and verify all 25 friend link endpoints field-by-field against Go backend.

Per D-301: Go LinkDTO.id is `int` (raw DB ID), but NestJS currently uses `generatePublicID()` returning a Sqids string. This breaks frontend batch operations where `Number(id)` on a Sqids string produces NaN.

Per D-303: Fix direction is to return raw DB int, matching Go behavior.

Purpose: Eliminate the single HIGH-risk incompatibility in Phase 14 scope and verify all link endpoint response structures match Go.
Output: Fixed link.service.ts + comprehensive link verification test suite
</objective>
