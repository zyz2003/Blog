    - GET /atom.xml: Verify same content (Go registers /atom.xml route too)

    - Test 2: GET /sitemap.xml returns Cache-Control: public, max-age=3600
    - Test 3: Sitemap has XML declaration and urlset root element
    - Test 4: Sitemap url elements have loc, lastmod, changefreq, priority children
    - Test 5: GET /robots.txt returns Content-Type text/plain; charset=utf-8
    - Test 6: robots.txt contains User-agent, Allow, Disallow, Sitemap directives
  </behavior>
  <action>
    Extend `server/test/phase14-verification/seo-verification.spec.ts` with sitemap and robots.txt tests:

    **Sitemap verification (per Go sitemap_handler):**
    - GET /sitemap.xml: Note this endpoint bypasses global prefix (excluded in main.ts per D-246). Request goes to `/sitemap.xml` NOT `/api/sitemap.xml`.
    - Verify Content-Type header contains `text/xml`
    - Verify Cache-Control header contains `public, max-age=3600`
    - Verify response body starts with `<?xml version="1.0" encoding="UTF-8"?>` declaration
    - Verify `<urlset>` root element with xmlns attribute
    - Verify `<url>` child elements with `<loc>`, `<lastmod>`, `<changefreq>`, `<priority>` children
    - Verify loc values are valid URLs
    - Verify lastmod values are valid date strings

    **robots.txt verification (per Go handler):**
    - GET /robots.txt: Note this endpoint bypasses global prefix (excluded in main.ts per D-246). Request goes to `/robots.txt` NOT `/api/robots.txt`.
    - Verify Content-Type header contains `text/plain`
    - Verify Cache-Control header contains `public, max-age=86400` (24 hours, longer than RSS/sitemap)
    - Verify response body contains `User-agent:` directive
    - Verify response body contains `Allow:` directive
    - Verify response body contains `Disallow:` directive
    - Verify response body contains `Sitemap:` directive pointing to sitemap.xml URL

    **Note:** Like RSS, these endpoints return raw content (XML or plain text), NOT wrapped in { code, data, message }. Use `res.text` for assertions.
  </action>

    - Sitemap has XML declaration and urlset/url structure matching Go
    - robots.txt returns plain text with correct Content-Type and cache headers

    - All SEO verification tests pass
  </done>
