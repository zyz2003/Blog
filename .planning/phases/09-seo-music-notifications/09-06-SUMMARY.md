## What Was Built

### SubscriberRepository
- `findByEmail(email)` — Select from subscribers where email matches
- `create({ email, isActive, token })` — Insert new subscriber, return created record
- `updateIsActive(id, isActive)` — Update isActive + updatedAt by id
- `findByToken(token)` — Select from subscribers where token matches
- `findActiveSubscribers()` — Select all where isActive=true

### DTOs
- `SubscribeDto` — `{ email: string, code: string }` with @IsEmail + @IsString validation
- `UnsubscribeDto` — `{ email: string }` with @IsEmail validation
- `SendVerificationCodeDto` — `{ email, turnstile_token?, geetest_*?, image_captcha_id/answer? }` with @IsOptional + @IsString on captcha fields

### SubscriberService
- `subscribe(email, code)` — Verify code from MemoryCache (one-time use), create new subscriber or reactivate inactive one
- `unsubscribe(email)` — Find by email, set isActive=false
- `unsubscribeByToken(token)` — Find by 64-char hex token, set isActive=false
- `sendVerificationCode(email)` — Generate 6-digit code (crypto.randomBytes(4) + UInt32BE + modulo 1000000), store in MemoryCache with 5min TTL, send via EmailService
- `notifyArticlePublished(article)` — Get active subscribers, send emails with 100ms delay, try-catch per email
- `generateToken()` — crypto.randomBytes(32).toString('hex') matching Go
- `generateVerificationCode()` — crypto.randomBytes(4) + readUInt32BE(0) % 1000000 + padStart(6, '0') matching Go

### SubscriberController
- `POST /api/public/subscribe` — @Public(), @Throttle(3/60s), accepts SubscribeDto
- `POST /api/public/subscribe/code` — @Public(), @Throttle(3/60s), CaptchaService.verify() then sendVerificationCode
- `POST /api/public/unsubscribe` — @Public(), accepts UnsubscribeDto
- `GET /api/public/unsubscribe/:token` — @Public(), token-based unsubscribe

### SubscriberModule
- Imports: DatabaseModule, CommonModule, CaptchaModule
- Controllers: [SubscriberController]
- Providers: [SubscriberService, SubscriberRepository]
- Exports: [SubscriberService] — for ArticleService integration
