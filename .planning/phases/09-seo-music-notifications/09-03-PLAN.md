  <action>
Create three files for the Email module:

**email.templates.ts** — HTML email templates as string functions:
1. `verificationEmailTemplate(params: { appName: string, code: string, expiryMinutes: number })` — Returns HTML string for verification code email. Contains: app name header, 6-digit code displayed prominently, expiry notice (5 minutes), footer with app name.
2. `articlePushEmailTemplate(params: { appName: string, articleTitle: string, articleUrl: string, unsubscribeUrl: string })` — Returns HTML string for article notification email. Contains: app name header, article title as link, unsubscribe link at bottom.

**email.service.ts** — EmailService with nodemailer:
1. **Constructor** — Inject SettingsService. Create a private `transporter` property (nodemailer.Transporter | null). Do NOT create transporter in constructor — defer to first send call (lazy init) because SMTP config may not be available at startup.

2. **private getTransporter()** — Lazy-init nodemailer transporter:
   - Read SMTP config from SettingsService: `smtp.host`, `smtp.port`, `smtp.user`, `smtp.pass`, `smtp.from`
   - If any required field is missing (host, port, user, pass), return null (SMTP not configured)
   - Create transporter with `nodemailer.createTransport({ host, port: parseInt(port), auth: { user, pass }, secure: port === '465' })`
   - Cache the transporter instance for reuse
   - Return transporter

3. **async sendVerificationEmail(email: string, code: string)** — Per D-206:
   - Get transporter via getTransporter(). If null, return silently (no error).
   - Read appName from SettingsService.get('APP_NAME'), default 'Anheyu Blog'
   - Read smtpFrom from SettingsService.get('smtp.from'), fallback to smtp.user
   - Call transporter.sendMail({ from: `"${appName}" <${from}>`, to: email, subject: `${appName} - 邮箱验证码`, html: verificationEmailTemplate({ appName, code, expiryMinutes: 5 }) })
   - Wrap in try-catch: log error with NestJS Logger on failure, do NOT throw (email failure should not break the caller)

4. **async sendArticlePushEmail(email: string, articleTitle: string, articleUrl: string, unsubscribeUrl: string)** — Per D-206:
   - Get transporter via getTransporter(). If null, return silently.
   - Read appName and smtpFrom same as above
   - Call transporter.sendMail({ from, to: email, subject: `${appName} - 新文章发布: ${articleTitle}`, html: articlePushEmailTemplate({ appName, articleTitle, articleUrl, unsubscribeUrl }) })
   - Wrap in try-catch: log error, do NOT throw

5. **async sendMail(to: string, subject: string, html: string)** — Generic send method for future use. Same SMTP config and silent-skip logic.

**email.module.ts** — EmailModule:
- imports: [SettingsModule] (SettingsModule is @Global but explicit import for clarity)
- providers: [EmailService]
- exports: [EmailService]

**Package installation** — Per D-206, install nodemailer and its types:
- Run: `npm install nodemailer` and `npm install -D @types/nodemailer`
- Import nodemailer in email.service.ts: `import * as nodemailer from 'nodemailer'`
