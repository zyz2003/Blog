**Helper: toLinkResponseDTO(link, category?, tag?): LinkResponseDto**

Per D-175: Encode link.id with EntityType.Link using generatePublicID. Map all link fields to LinkResponseDto. Include category (LinkCategoryResponseDto) and tag (LinkTagResponseDto|null). Category and tag IDs are NOT Sqids-encoded (Go backend returns raw integer IDs for category/tag in LinkDTO).

**applyLink(dto: ApplyLinkRequestDto, ip: string): Promise<LinkResponseDto>**

Per D-170, D-171, D-176, and Go ApplyLink logic:

1. Rate limit check: linkApplyRateLimiter.checkLimit(ip, maxPerDay). Read maxPerDay from settings (KeyFriendLinkApplyLimit, default 1). If exceeded, throw LINK_APPLY_RATE_LIMITED.

2. Normalize email: lowercase, trim.

3. Check email repeat: repo.hasApplicationByEmail(email). If repeat applicant, CAPTCHA verification would be required (deferred per CONTEXT.md deferred ideas — skip CAPTCHA check for now, just log a warning).

4. Check URL exists: repo.findByUrl(dto.url). If exists and dto.type='NEW', throw LINK_URL_EXISTS. If exists and dto.type='UPDATE', the existing link's originalUrl should be set.

5. Get default category: Read KeyFriendLinkDefaultCategory from settings (default 2). Get category by ID. If not found, throw LINK_CATEGORY_NOT_FOUND.

6. Check card style siteshot: If category.style='card' and no dto.siteshot, throw LINK_SITESHOT_REQUIRED per D-177.

7. Create link with status='PENDING', default category ID. Set isBounce=false.

8. Async siteshot fetch per D-177: If siteshot is empty and screenshot API is configured in settings (KeyFriendLinkSiteshotApi + KeyFriendLinkSiteshotKey), fire async HTTP GET to screenshot API. On success, update link.siteshot. On failure, skip (siteshot remains empty, does not block creation). If no API configured, skip.

9. Pushoo notification per D-176: Fire-and-forget async notification. Read pushoo_channel and pushoo_url from settings. If configured, send POST with message about new link application. Follow the pattern from CommentService.firePushooNotification.

10. Return toLinkResponseDTO(createdLink, category, null).

**listPublicLinks(): Promise<LinkCategoryResponseDto[]>**

Per D-178: Get all APPROVED links with category and tag joins. Group by category. For each category, build LinkCategoryResponseDto with associated links array. Only include categories that have at least one APPROVED link.

**getRandomLinks(count: number): Promise<LinkResponseDto[]>**

Per D-174: If count=0, return all APPROVED links. If count>0, return count random APPROVED links via repo.findRandomApproved(count). Map each to LinkResponseDto.

**checkLinkExists(url: string): Promise<CheckExistsResponseDto>**

Per D-174: Check if any APPROVED link exists with given URL. Return {exists: boolean, url}.

**listApplications(): Promise<LinkResponseDto[]>**

Per D-174: Get all links (all statuses, non-deleted). Map to LinkResponseDto. This is a public endpoint showing all applications.

**adminCreateLink(dto: AdminCreateLinkRequestDto): Promise<LinkResponseDto>**

1. Decode category_id (Sqids) to DB ID using decodePublicID, verify EntityType.
2. Decode tag_id if provided.
3. Create link via repo.create with all fields from dto.
4. If tag_id provided, set link-tag pivot via repo.setLinkTag.
5. Return toLinkResponseDTO.

**adminListLinks(filters): Promise<LinkListResponseDto>**

1. Decode status/category/tag filter IDs if provided.
2. Call repo.adminList with filters.
3. For each link, get category and tag, map to LinkResponseDto.
4. Return { list, total, page, pageSize }.

**adminUpdateLink(publicId: string, dto: UpdateLinkRequestDto): Promise<LinkResponseDto>**

1. Decode publicId with EntityType.Link.
2. Get existing link. If not found, throw LINK_NOT_FOUND.
3. If link was APPROVED and status is changing, set status='UPDATED' per D-170 (requires re-review).
4. Update link fields via repo.update.
5. If tag_id provided, update link-tag pivot.
6. Return toLinkResponseDTO.

**adminDeleteLink(publicId: string): Promise<void>**

1. Decode publicId with EntityType.Link.
2. Soft-delete via repo.softDelete([dbId]).

**adminBatchDeleteLinks(dto: BatchDeleteLinksRequestDto): Promise<BatchDeleteLinksResponseDto>**

1. Decode all public IDs to DB IDs.
2. Soft-delete via repo.softDelete(dbIds).
3. Return { total, success, failed, failed_list }.

**reviewLink(publicId: string, dto: ReviewLinkRequestDto): Promise<LinkResponseDto>**

Per D-170 and Go ReviewLink logic:

1. Decode publicId with EntityType.Link.
2. Get existing link.
3. If dto.status='APPROVED': Check link has category. If category style='card', siteshot must be provided and non-empty. If missing, throw LINK_SITESHOT_REQUIRED.
4. Update status via repo.updateStatus. If dto.siteshot provided, also update siteshot.
5. Return toLinkResponseDTO.

Note: Category and Tag IDs in responses are raw integers (NOT Sqids-encoded), matching Go backend LinkCategoryDTO/LinkTagDTO which use int IDs.

**importLinks(dto: ImportLinksRequestDto): Promise<ImportLinksResponseDto>**

Per D-173 and Go ImportLinks logic:

1. Validate: at least 1 link, max 1000.
2. Build category cache: Map<string, categoryId> from repo.findAllCategories.
3. Build tag cache: Map<string, tagId> from repo.findAllTags.
4. Track processedURLs: Set for intra-import dedup.
5. For each ImportLinkItem:
   a. Resolve category: by category_name from cache. If not found and create_categories=true, create via repo.createCategory. If not found and create_categories=false, use default_category_id.
   b. Check intra-import dedup: if URL already in processedURLs, add to skipped_list.
   c. If skip_duplicates=true, check DB for existing URL+category. If exists, add to skipped_list.
   d. Resolve tag: by tag_name from cache. If not found and create_tags=true, create via repo.createTag with tag_color or '#409EFF'. If not found and create_tags=false, skip tag.
   e. Set default status: 'PENDING' if empty.
   f. Create via repo.create. Set link-tag pivot if tag resolved.
   g. Add to success_list or failed_list.
6. Return ImportLinksResponseDto with counts and lists.

**exportLinks(filters?): Promise<ExportLinksResponseDto>**

Per D-173: Get all matching links (all non-deleted). For each link, convert to ImportLinkItem format with category_name, tag_name, tag_color. Return { links, total }.

**healthCheck(): Promise<void>**

Per D-172 and Go HealthCheck logic:

1. Check if health check is already running. If yes, throw LINK_HEALTH_CHECK_RUNNING.
2. Set health check status: is_running=true, start_time=now, result=null, error=''.
3. Fire async processing (do NOT await):
   a. Get all APPROVED + INVALID links where skipHealthCheck=false.
   b. Create HTTP client with 10s timeout.
   c. Process links with max 10 concurrent (use a simple semaphore pattern with a counter).
   d. For each link: HTTP GET to link.url with 10s timeout. Status 2xx/3xx = healthy.
   e. APPROVED links that fail -> mark INVALID.
   f. INVALID links that recover -> mark APPROVED.
   g. Update health check status: is_running=false, end_time=now, result={total, healthy, unhealthy, unhealthy_ids}.
   h. On error: set error message, is_running=false.
4. Return immediately (async processing in background).

**getHealthCheckStatus(): Promise<HealthCheckStatusDto>**

Return current health check status from in-memory state.

**batchUpdateSort(dto: BatchUpdateSortRequestDto): Promise<void>**

| T-07-15 | Information Disclosure | Health check reveals link URLs to admin | low | accept | Admin-only endpoint; URLs are already known to admin |
