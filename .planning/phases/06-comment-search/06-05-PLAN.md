  <action>
Create WeatherModule directory and files:

GeoIPService (@Injectable(), per D-143):
- Private cache: Map<string, { location: any, expiresAt: number }> for caching successful lookups
- lookup(ip: string, referer?: string): Make HTTP GET request to https://api.nsuuu.com/api/ip-location with ip parameter. Use fetch() or axios (if already installed) for the HTTP call. Parse response JSON. Extract location data (latitude, longitude, city, province, country). Return structured location object.
- If request fails (network error, timeout, invalid response): return null. Let the caller handle fallback.
- isPrivateIP(ip: string): Check if IP is in private ranges (10.*, 172.16-31.*, 192.168.*, 127.*). Return boolean.
- Cache behavior: before making HTTP call, check cache. If cached entry exists and expiresAt > Date.now(), return cached result. After successful lookup, store in cache with expiresAt = Date.now() + 300000 (5 minutes). For private IPs, skip lookup and return null immediately.

WeatherController (@Controller('public/weather'), @Public()):
- @Get('ip-location') getIPLocation(@Req() req: any): Extract IP from req (x-forwarded-for header or req.ip). Call geoipService.lookup(ip). If lookup returns null or IP is private, return default coordinates from settings: read sidebar.weather.rectangle from SettingsService (this is a configured default coordinate string like "116.407526,39.90403" or similar). Parse rectangle into latitude/longitude values. Return { ip_location: { latitude, longitude, city, province, country } or default coordinates }. Per D-144.

WeatherModule:
- imports: [SettingsModule]
- providers: [GeoIPService]
- controllers: [WeatherController]
- exports: [GeoIPService] (shared with CommentModule for comment IP location lookup)

Note: GeoIPService is exported from WeatherModule so CommentModule can import it and use the same IP location lookup for comment creation (per D-143, D-159). CommentService will inject GeoIPService for the lookupIPLocation method.
