## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → POST /api/ai/chat | Anonymous untrusted input crosses here — @Public() route, no JWT required (D-360) |
| ChatService → LLM Provider | Outbound API call with user-supplied message content |
| streamText → tool execute | Tool execution with LLM-generated arguments (search keyword, article ID) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-01 | Spoofing | POST /api/ai/chat (@Public) | high | mitigate | @Throttle({ default: { ttl: 6000, limit: 1 } }) limits abuse per D-360; anonymous route accepted as business decision |
| T-18-02 | Tampering | ChatService message input | medium | mitigate | UIMessage[] validated non-empty in pre-stream check (D-369); convertToModelMessages handles format validation |
| T-18-03 | Information Disclosure | LLM API key in error messages | high | mitigate | ModelResolver wraps errors in DomainError with generic message; onError callback logs internally but stream error frames use toUIMessageStream onError to sanitize |
| T-18-04 | Denial of Service | Unbounded tool call loop | high | mitigate | stopWhen: stepCountIs(5) caps tool loop at 5 iterations per D-365 |
| T-18-05 | Tampering | Tool execute arguments from LLM | medium | accept | Tools delegate to SearchService/ArticleService which have their own input validation; article ID decode uses decodePublicID with try-catch |
| T-18-SC | Tampering | npm installs (ai already installed) | low | accept | ai@7.0.37 already in package.json from Phase 16; no new package installs in this plan |
</threat_model>
