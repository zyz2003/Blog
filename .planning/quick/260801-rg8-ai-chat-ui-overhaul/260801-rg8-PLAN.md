# Quick Task 260801-rg8: 前台 AI 对话 UI 大改优化

## 背景

当前 chat UI 过于简陋：纯 muted 方块气泡、无头像/无发送方身份、无动效、emoji 当图标（📄🗂🏷⏱，违反 ui-ux-pro-max 清单）、单行 input、代码块无复制/无语言标签、空状态仅一行字+胶囊。调研 setproduct / thefrontkit / aisdkagents + ui-ux-pro-max skill，采用 **AI-Native UI** 风格。

## 设计决策（已与用户确认）

- **布局**：混合 — 助手有左侧渐变头像 + 轻背景弱气泡（bg-muted/60，rounded-2xl，无强边框），拿全宽感又保留气泡轮廓；用户消息右紧凑强调气泡
- **代码块**：零依赖样式化 — 暗底 + 语言标签 + 复制按钮 + 横向滚动，不做语法高亮
- **配色**：沿用博客现有 token（--primary 蓝 #163bf2 / 暗色金 #dfa621），不引入 skill 推荐的青绿调（会撞色）
- **图标**：lucide-react，清掉所有 emoji 图标
- **依赖**：零新增（继续 marked + DOMPurify）
- **后端不动**，API 兼容性不受影响
