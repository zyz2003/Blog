## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → GET /api/ai/conversations/:id/messages | Public endpoint — conversation content visible to anyone with the Sqids ID |
| browser → localStorage | conversationId stored client-side — can be manipulated |
| admin → AiChatForm settings | Admin-only, writes to settings table |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation |
|-----------|----------|-----------|----------|-------------|------------|
| T-19-04 | Information Disclosure | Conversation messages via public endpoint | medium | accept | Sqids IDs are non-sequential; personal blog scale; same risk as Phase 18 anonymous chat |
| T-19-05 | Tampering | localStorage conversationId | low | accept | Invalid ID returns 404 from backend; no data corruption possible |
| T-19-06 | Information Disclosure | ai_chat_system_prompt in public settings | low | accept | System prompt is not sensitive — it's the instruction given to the AI assistant |
</threat_model>
