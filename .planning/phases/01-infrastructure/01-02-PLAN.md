    Implement shuffleAlphabet(seed: string): string. Step 1: compute seedInt as BigInt, iterating over seed chars: seedInt += BigInt(charCodeAt(i)) * BigInt(i + 1). Step 2: implement Go's math/rand.NewSource LCG. Go 1.25 uses the autoseed-based PCG algorithm for math/rand, but when explicitly calling mrand.NewSource(seedInt), it uses the legacy glibc-style LCG: state[0] = seedInt, then each next value: seed = (seed * 1103515245 + 12345) & 0x7fffffff. Step 3: Fisher-Yates shuffle using the LCG: for i from len-1 down to 1, j = nextInt(i+1), swap alphabet[i] and alphabet[j]. The nextInt(n) function: v = lcg.next(), return v % n. IMPORTANT: test this against Go output with a known seed to verify compatibility.

    Implement initSqidsEncoderWithSeed(seed: string): initializes Sqids with shuffled alphabet (or default if seed empty), minLength=4. Store the encoder instance in a module-level variable.

    Implement generatePublicID(dbID: number, entityType: number): string -- encodes [dbID, entityType] using sqids encoder. Returns the encoded string.

    Implement decodePublicID(publicID: string): { dbID: number, entityType: number } -- decodes publicID, verifies exactly 2 numbers returned, returns { dbID: numbers[0], entityType: numbers[1] }.

Start a setInterval(cleanup, 60000) in constructor (clean every 60s). Provide stop() method to clear interval. Per D-14.
