## Goal

## Tasks

### 1. Create DocSeriesService

Create `server/src/doc-series/doc-series.service.ts`:

```typescript
@Injectable()
export class DocSeriesService {
  constructor(
    private readonly docSeriesRepo: DocSeriesRepository,
    @Inject(DRIZZLE) private readonly db: any,
  ) {}
```

Methods matching Go `pkg/service/doc_series/service.go`:

**create(req: CreateDocSeriesRequest)** —
1. Check name uniqueness via docSeriesRepo.existsByName(req.name)
2. If exists → throw BadRequestException("系列名称 'X' 已存在")
3. Call docSeriesRepo.create(req)
4. Return DocSeriesResponse

**list(opts: ListDocSeriesOptions)** —
1. Call docSeriesRepo.list(opts)
2. Map each DocSeries to DocSeriesResponse
3. Return DocSeriesListResponse { list, total, page, pageSize }

**getById(publicID: string)** —
1. Call docSeriesRepo.getById(publicID)
2. Return DocSeriesResponse

**getByIdWithArticles(publicID: string)** —
1. Call docSeriesRepo.getByIdWithArticles(publicID)
2. Return DocSeriesWithArticles

**update(publicID: string, req: UpdateDocSeriesRequest)** —
1. If req.name provided:
   a. Check name uniqueness via existsByName
   b. Get current series to compare name
   c. If name exists and is different from current → throw error
2. Call docSeriesRepo.update(publicID, req)
3. Return DocSeriesResponse

**delete(publicID: string)** —
1. Get series by ID
2. If docCount > 0 → throw BadRequestException("无法删除，该系列下还有 N 篇文档")
3. Call docSeriesRepo.delete(publicID)

**toAPIResponse(ds)** — Private helper:
- Map DocSeries domain model to DocSeriesResponse
- ID is already Sqids-encoded by repository

### 2. Article Association Note

The DocSeries ↔ Article relationship is managed through the articles table's `doc_series_id` and `doc_sort` fields. In the Go backend, article associations are managed through the Article CRUD endpoints (not through DocSeries endpoints). The DocSeries endpoints only read article associations (GetByIDWithArticles).

The DocSeriesService does NOT need methods like assignArticleToSeries or removeArticleFromSeries because:
- Go backend's CreateDocSeriesRequest/UpdateDocSeriesRequest have no article fields
- Article association is managed by setting article.doc_series_id + article.doc_sort via Article CRUD
- DocSeries delete is blocked when docCount > 0 (articles must be unlinked first via Article CRUD)
- The doc_count field is maintained by the Article service when articles are linked/unlinked

The existing Article module (Phase 03) already handles the article table including doc_series_id and doc_sort fields. If ArticleService needs to update doc_count on DocSeries when articles are linked/unlinked, it can inject DocSeriesService or DocSeriesRepository for that purpose.
