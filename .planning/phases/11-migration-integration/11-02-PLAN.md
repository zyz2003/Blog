## Tasks

### Task 1: Create shared test helpers with typed interface

**File:** `server/test/helpers/api-compat-helpers.ts`

1. **Export `TestContext` interface** (contract for 11-03/04/05):
   ```typescript
   export interface TestContext {
     app: INestApplication;
     db: any; // BetterSQLite3Database
     adminToken: string;
     request: (method: string) => supertest.Test; // bound to app
     ts: number; // unique timestamp for test data
   }
   ```

2. **`createTestApp()` → `Promise<TestContext>`**
   - Initialize Sqids with test seed
   - Create NestJS Test module with AppModule
   - Set global prefix 'api' and ValidationPipe
   - Get DRIZZLE token
   - Seed base data (user_groups, users, settings)
   - Initialize app
   - Generate admin JWT token
   - Return TestContext

3. **`seedBaseData(db)`**
   - Insert user_groups (id=1, Admin)
   - Insert users (id=1, admin, hashed password)
   - Insert settings (JWT_SECRET, id_seed, APP_NAME, captcha.provider, GRAVATAR_URL)
   - Use onConflictDoNothing/onConflictDoUpdate for idempotency

4. **`generateAdminToken(seed: string, jwtSecret: string)` → string**
   - Generate public IDs for user and user group
   - Sign JWT with HS256, 15min expiry
   - Return token string

5. **`assertSuccessResponse(res, expectedCode = 200)`**
   - `expect(res.body).toHaveProperty('code', expectedCode)`
   - `expect(res.body).toHaveProperty('message')`
   - `expect(res.body).toHaveProperty('data')`

6. **`assertPaginatedResponse(res, listKey = 'list', pageKey = 'pageNum')`**
   - Assert success response
   - Assert data has: list, total, pageKey, pageSize
   - Assert data[listKey] is array

7. **`assertErrorResponse(res, status, code?)`**
   - Assert status code
   - Assert body has code, message
   - If code provided, assert body.code matches

8. **`closeTestApp(app)`**
   - Close NestJS app

9. **`uploadFile(app, path, fieldName, buffer, token?, extraFields?)`** — Multipart upload helper
   - Create supertest request with .attach() and .field()
   - Return response

**Verification:** `npx tsx -e "import { TestContext, createTestApp, assertSuccessResponse } from './server/test/helpers/api-compat-helpers'; console.log('OK')"` — compiles without errors.

### Task 2: Auth API compat tests

**File:** `server/test/api-compat/auth-api-compat.spec.ts`

Test all 7 auth endpoints:
1. `POST /api/auth/login` — Success: `{ code: 200, data: { token, refresh_token, user }, message }`
2. `POST /api/auth/login` (invalid credentials) — Error: 401, `{ code, message, data: null }`
3. `POST /api/auth/refresh-token` — Success with refresh_token in body
4. `POST /api/auth/register` — Response shape (may fail if registration disabled, verify error format)
5. `POST /api/auth/forgot-password` — Response shape
6. `POST /api/auth/reset-password` — Response shape
7. `GET /api/auth/check-email` — Response shape

Assertions per endpoint:
- Response wrapper: `{ code, data, message }`
- Login success: data has token (string), refresh_token (string), user (object with id/nickname/email)
- Error response: data is null, message is Chinese text
- Status codes match Go backend

**Verification:** `npx vitest run server/test/api-compat/auth-api-compat.spec.ts --reporter=verbose`

## Test Data Strategy

Each test file:
1. Calls `createTestApp()` in `beforeAll` (60s timeout)
2. Seeds module-specific data after base data
3. Uses unique timestamps in test data to avoid conflicts
4. Cleans up in `afterAll` via `closeTestApp()`
