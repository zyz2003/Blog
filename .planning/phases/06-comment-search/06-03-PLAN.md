Create CommentService as @Injectable(). Inject CommentRepository, SettingsService, CommentRateLimiter. Import renderCommentMarkdown, generatePublicID, decodePublicID, EntityType, ErrorCodes.

CREATE METHOD (matches Go service.go lines 219-606):
1. Rate limit check: call rateLimiter.checkLimit(ip, limitPerMinute) where limitPerMinute comes from settingsService.Get('comment_limit_per_minute') parsed as int. Per D-130.
2. Decode parentId: if req.parent_id is not empty, decodePublicID to get { dbID, entityType }. Verify entityType === EntityType.Comment. Fetch parent by dbID via repo.findById. Verify parent.targetPath === req.target_path. If parent.isAnonymous, throw ErrAnonymousNoReply. Per D-118.
3. Decode replyToId: if req.reply_to_id is not empty, decodePublicID. Verify entityType === EntityType.Comment. Fetch replyTo by dbID via repo.findById. Verify replyTo.targetPath === req.target_path. If replyTo.isAnonymous, throw ErrAnonymousNoReply. Per D-126 step 4.
4. Also check parentComment.isAnonymous for direct reply scenario (matching Go line 275-277).
5. Markdown rendering: call renderCommentMarkdown(req.content) to get contentHtml. Per D-122, D-125.
6. Compute emailMd5: if req.email provided, lowercase it, compute MD5 hex digest. Per D-126 step 6.
7. IP geolocation: call lookupIPLocation(ip, referer) method — stub that returns string from NSUUU API or defaults to Chinese for unknown. Per D-143. Implementation: HTTP GET to https://api.nsuuu.com/api/ip-location?ip={ip}, parse response, extract location string, fallback to Chinese default.
8. Forbidden words: read settings comment_forbidden_words (comma-separated), split and trim. If any word found in req.content (case-sensitive contains), set status=2 (Pending). Per D-131.
9. Admin detection: if claims exist (user is authenticated), decode claims.UserID to get userDbId, fetch user from userRepo (inject UserRepository or use a minimal lookup). If user.userGroup.id === 1 AND req.email matches user.email, set isAdmin=true, status=1 (Published). Per D-127. If claims null and email is not empty, query admins with groupId=1; if email matches any admin, throw ErrAdminEmailUsedByGuest. Per D-129. If admin query fails, log warning and skip (matching Go line 347).
10. Anonymous validation: if req.is_anonymous is true, get settings comment_anonymous_email. If configured and req.email does not match, throw ErrAnonymousEmailMismatch. Per D-128.
11. Create comment record: call repo.create with all fields. Per D-126 step 11.
12. Pushoo notification: if newComment.status === 1 (Published), fire Pushoo notification in async (fire-and-forget). Read pushChannel from settings pushoo_channel, pushUrl from pushoo_url. If pushChannel is empty, skip. Per D-153, D-155. Two scenarios: (a) notify admin of new comment if comment is not from admin and parent is not admin; (b) notify admin if reply is to admin's comment. Matching Go lines 546-597. Build notification message with comment info, POST to pushUrl with channel and token from settings.
13. Return toResponseDTO(newComment, parentComment, replyToComment, false).

LISTBYPATH METHOD (matches Go service.go lines 608-782):
1. Fetch all published comments for path: repo.findAllPublishedByPath(path). Limit 500. Per D-119.
2. Build commentMap: Map<number, Comment> for O(1) lookups.
3. Identify rootComments: comments where parentId is null (IsTopLevel).
4. Build descendantsMap: for each non-root comment, trace ancestors upward to find root (cycle detection with visited set). Add to descendantsMap[rootID]. Per D-119 step 2.
5. Sort roots: pinned first (pinnedAt desc), then by createdAt desc. Per D-119 step 3.
6. Compute totalRootComments and totalWithChildren.
7. Paginate roots: slice [start, end]. Per D-119 step 4.
8. For each paginated root, build response:
   a. rootResp = toResponseDTO(root, null, null, false)
   b. rootResp.totalChildren = descendantsMap[root.ID].length
   c. Find chainHeads: descendants where replyToId equals root.ID or replyToId is null. Per D-119 step 5.
   d. Take first 3 chainHeads (previewLimit).
   e. Recursively collect full chain for each selected chainHead: collectChain function traverses replyToId links in descendants. Per Go lines 721-745.
   f. Map collected children to ResponseDTO with parent and replyTo from commentMap.
   g. rootResp.children = childResponses
9. Return ListResponse: { list, total: totalRootComments, total_with_children: totalWithChildren, page, pageSize, has_more: allComments.length >= 500 }.

LISTLATEST METHOD (matches Go service.go lines 138-217):
1. Validate page/pageSize.
2. Fetch paginated published comments: repo.findAllPublishedPaginated(page, pageSize).
3. Collect parentIDs and replyToIDs.
4. Batch fetch referenced comments via repo.findManyByIDs.
5. Build commentMap for O(1) lookup.
6. For each comment, find parent and replyTo from commentMap. Prefer replyToId; fallback to parent for backward compatibility. Per Go lines 201-205.
7. Map to toResponseDTO(comment, parent, replyTo, false).
8. Return ListResponse: total = total_with_children (flat list, no tree).

LISTCHILDREN METHOD (matches Go service.go lines 784-942):
1. Decode parentPublicID via decodePublicID. Verify entityType === EntityType.Comment.
2. Fetch parent comment via repo.findById.
3. Get targetPath from parent.
4. Fetch all published comments for that path (same 500 limit).
5. Build commentMap.
6. Recursively find all descendants of parentDbId using parentId traversal (matching Go lines 812-819, using parentId not replyToId for descendant discovery).
7. Preview mode: if page===1 && pageSize<=3, use chainHead logic (3 chainHeads + chains), same as ListByPath but rooted at parentDbId. Per Go lines 822-887.
8. Normal mode: sort descendants by createdAt desc, paginate with offset/limit. Per Go lines 890-940.
9. For each child, map to toResponseDTO with parent and replyTo from commentMap.
10. Return ListResponse with total and total_with_children.

TORESPONSEDTO METHOD (matches Go service.go lines 944-1051):
1. Generate public ID: generatePublicID(c.id, EntityType.Comment).
2. Re-render content: call renderCommentMarkdown(c.content) for fresh emoji/extension rendering. Per Go line 954. If rendering fails, fall back to stored c.contentHtml.
3. Render image URLs: if contentHtml contains "anzhiyu://file/", call renderHTMLURLs method to replace internal URIs with signed download URLs. Per D-123. Implementation: regex match src="anzhiyu://file/{publicId}", for each match, decode publicId, lookup file record via db query, generate signed URL using existing sign logic (reuse from Phase 05 ThumbnailService signing pattern), replace in HTML. If comment_image storage policy has image_process.default_style configured, append "!{styleName}" suffix to URL per D-123.
4. Compute emailMd5: lowercase email, MD5 hex. Also detect QQ email pattern and extract qqNumber.
5. Get parentPublicId and replyToPublicId/replyToNick from parent/replyTo args.
6. Show UA/Region based on settings: read comment_show_ua and comment_show_region booleans from settings. If showUA is false, omit user_agent. If showRegion is false, omit ip_location. Per Go lines 997-1040.
7. Get avatarUrl: if c.userId is set, lookup user record and check for custom avatar. If avatar exists and is relative path, prepend gravatar base URL from settings. Per Go lines 1001-1009.
8. If isAdminView: populate email, ip_address, content (Markdown original), status fields. Otherwise omit these. Per D-138, D-207.
9. Return CommentResponseDto with all fields.
