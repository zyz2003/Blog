    Create 18 schema files under server/src/database/schemas/. Read each corresponding Go ent/schema/*.go file to map fields exactly. Per D-05, D-06.

    Apply the same type mapping rules as Plan 03:
    - Go field.Uint/Int/Int64 -> sqliteInteger
    - Go field.String/Text -> sqliteText
    - Go field.Time -> sqliteInteger({ mode: 'timestamp' })
    - Go field.JSON -> sqliteText({ mode: 'json' })
    - Go field.Enum -> sqliteText
    - Go field.Bool -> sqliteInteger({ mode: 'boolean' })
    - Go field.Other with SchemaType -> sqliteText (with mode: 'json' if JSON type)
    - SoftDeleteMixin -> add deletedAt: sqliteInteger('deleted_at', { mode: 'timestamp' })

    Key tables and their Go schema sources:

    direct-link.schema.ts: directLinks table from ent/schema/directlink.go. SoftDeleteMixin. Has fields for short-link access, expiration, URL reference.

    storage-policy.schema.ts: storagePolicies table from ent/schema/storagepolicy.go. SoftDeleteMixin. Has fields for storage type (local/remote), settings JSON, policy name.

    comment.schema.ts: comments table from ent/schema/comment.go. SoftDeleteMixin. Has fields for nested replies (parentId), article reference, author info, moderation status, pinned/liked status.

    link.schema.ts: links table from ent/schema/link.go. SoftDeleteMixin. Friend links with URL, description, health check status.

    link-category.schema.ts: linkCategories table from ent/schema/linkcategory.go. SoftDeleteMixin. Categories for friend links.

    link-tag.schema.ts: linkTags table from ent/schema/linktag.go. SoftDeleteMixin. Tags that can be applied to friend links.

    link-tag-pivot.schema.ts: linkTagPivot table. This is the join table implied by the many-to-many edge between Link and LinkTag in Go ent/schema. Fields: id, linkId (references links.id), linkTagId (references link_tags.id), createdAt. This table is NOT in the Go ent/schema directory as a standalone file -- it is created by ent's implicit many-to-many edge handling.

    album.schema.ts: albums table from ent/schema/album.go. SoftDeleteMixin. Photo albums with cover, description, category.

    album-category.schema.ts: albumCategories table from ent/schema/albumcategory.go. SoftDeleteMixin.

    doc-series.schema.ts: docSeries table from ent/schema/docseries.go. SoftDeleteMixin. Document series for ordered article collections.

    notification-type.schema.ts: notificationTypes table from ent/schema/notificationtype.go. SoftDeleteMixin.

    user-notification-config.schema.ts: userNotificationConfigs table from ent/schema/usernotificationconfig.go. SoftDeleteMixin. Per-user notification preferences.

    user-installed-theme.schema.ts: userInstalledThemes table from ent/schema/userinstalledtheme.go. SoftDeleteMixin. Tracks which themes a user has installed.

    subscriber.schema.ts: subscribers table from ent/schema/subscriber.go. SoftDeleteMixin. Email subscribers with unsubscribe tokens.

    visitor-log.schema.ts: visitorLogs table from ent/schema/visitor_log.go. SoftDeleteMixin. Raw visitor access logs with UA, IP, referrer.

    visitor-stat.schema.ts: visitorStats table from ent/schema/visitor_stat.go. SoftDeleteMixin. Aggregated visitor statistics.

    url-stat.schema.ts: urlStats table from ent/schema/url_stat.go. SoftDeleteMixin. Per-URL access statistics.

    tag.schema.ts: tags table from ent/schema/tag.go. SoftDeleteMixin. Generic tag table.

    For each schema: export the sqliteTable result as a named const. Use snake_case column names and camelCase property names. Include all indexes defined in Go schema Indexes() methods.
