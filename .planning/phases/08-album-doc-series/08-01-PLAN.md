### 5. Create AlbumRepository

Create `server/src/album/album.repository.ts`:

```typescript
@Injectable()
export class AlbumRepository {
  constructor(@Inject(DRIZZLE) private readonly db: any) {}
```

Methods (matching Go album_repo.go + album_repo interface):

- **create(album)** — Insert into albums table, return created record
- **createOrRestore(album)** — Transaction:
  1. Query albums WHERE fileHash = album.fileHash (include soft-deleted records — query WITHOUT deletedAt IS NULL filter, so we find both active and soft-deleted records)
  2. If not found → insert new → return { album, status: 'created' }
  3. If found + deletedAt not null (soft-deleted) → update: set deletedAt = NULL (restore), update all fields → return { album, status: 'restored' }
  4. If found + deletedAt null (active) → return { album, status: 'existed' }
- **findById(id)** — Select by id WHERE deletedAt IS NULL (only return active records)
- **update(album)** — Update all fields by id WHERE deletedAt IS NULL
- **delete(id)** — **Soft delete**: set deletedAt = new Date() WHERE id = X (Go backend uses SoftDeleteMixin which intercepts DeleteOneID and converts it to an UpdateOneID setting deleted_at = time.Now())
- **batchDelete(ids)** — **Soft delete**: set deletedAt = new Date() WHERE id IN ids, return deleted count
- **findListByOptions(opts)** — Paginated query with filters. **All queries MUST include WHERE deleted_at IS NULL** to exclude soft-deleted records (Go's SoftDeleteMixin does this automatically via privacy policy):
  - categoryId filter: WHERE category_id = X AND deleted_at IS NULL
  - tag filter: SQLite: `(',' || tags || ',') LIKE '%,tag,%'` (with deleted_at IS NULL)
  - time range: created_at >= start AND created_at <= end (with deleted_at IS NULL)
  - sort: display_order_asc → ORDER BY display_order ASC, created_at DESC; created_at_asc; created_at_desc; view_count_desc → ORDER BY view_count DESC, created_at DESC
  - Pagination: LIMIT + OFFSET
  - Return { items, total }
- **incrementViewCount(id)** — UPDATE albums SET view_count = view_count + 1 WHERE id = X AND deleted_at IS NULL
- **incrementDownloadCount(id)** — UPDATE albums SET download_count = download_count + 1 WHERE id = X AND deleted_at IS NULL
- **findAllForDedup()** — Get all albums (for import/batch dedup), return fileHash→id map. **Include soft-deleted records** (no deletedAt filter) so dedup catches both active and deleted albums.

### 7. Create DocSeriesRepository

Create `server/src/doc-series/doc-series.repository.ts`:

Methods:
- **create(req)** — Insert into doc_series, return with Sqids-encoded ID
- **update(publicID, req)** — Decode Sqids → dbID, partial update non-nil fields
- **delete(publicID)** — Decode Sqids → dbID, hard delete
- **list(opts)** — Paginated query, ORDER BY sort ASC, created_at DESC. Return { items, total }
- **getById(publicID)** — Decode Sqids → dbID, select by id
- **getByIdWithArticles(publicID)** — Decode Sqids → dbID, select doc_series + query articles WHERE doc_series_id=dbID AND is_doc=true AND status='PUBLISHED' AND deleted_at IS NULL, ORDER BY doc_sort ASC, created_at ASC. Return DocSeriesWithArticles.
- **updateDocCount(dbID, delta)** — UPDATE doc_series SET doc_count = doc_count + delta WHERE id = X
- **existsByName(name)** — COUNT WHERE name = X, return boolean
