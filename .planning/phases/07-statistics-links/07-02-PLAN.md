Create LinkRepository as an @Injectable() provider. Inject DRIZZLE token from DatabaseModule. Implement the following methods using Drizzle query builder:

**Link CRUD:**

1. create(params): Insert into links table with all fields (name, url, rssUrl?, logo?, description?, status, siteshot?, email?, type?, originalUrl?, updateReason?, sortOrder, skipHealthCheck, categoryId). Returns inserted record.

2. findById(dbId: number): Single link by id where deletedAt is null. Returns link or undefined.

3. findByUrl(url: string): Find link where url matches and deletedAt is null. Returns link or undefined. Used for URL dedup check in ApplyLink.

4. hasApplicationByEmail(email: string): Check if any non-deleted link exists with given email. Returns boolean. Used for repeat applicant detection in ApplyLink.

5. findApprovedLinks(): Query all links where status='APPROVED' and deletedAt is null. Join with linkCategories and linkTagPivot+linkTags to include category and tag data. Order by sortOrder ASC. Returns array with joined data.

6. findRandomApproved(count: number): Query APPROVED links with ORDER BY RANDOM() LIMIT count. Join with category and tag. Returns array. Uses sql template for RANDOM().

7. adminList(filters: { page, pageSize, status?, categoryId?, tagId? }): Build dynamic query with optional filters. Paginated. Join with category and tag. Returns { list, total }.

8. update(dbId: number, data: Partial<Link>): Update specified fields, set updatedAt=now. Returns updated record.

9. updateStatus(dbId: number, status: string, siteshot?: string, rejectReason?: string): Update status field. Optionally update siteshot. Returns void.

10. softDelete(dbIds: number[]): Update deletedAt=now where id IN dbIds.

11. batchUpdateSort(items: Array<{id: number, sortOrder: number}>): For each item, update sortOrder. Use Drizzle sql template for batch: UPDATE links SET sort_order = CASE id WHEN ? THEN ? ... END WHERE id IN (...).

12. findLinksForHealthCheck(): Query links where status IN ('APPROVED','INVALID') AND skipHealthCheck=false AND deletedAt is null. Returns array.

**Category CRUD:**

13. createCategory(params: { name, style, description? }): Insert into link_categories. Returns record.

14. findAllCategories(): Query all link_categories. Returns array.

15. findCategoryById(dbId: number): Single category by id. Returns category or undefined.

16. updateCategory(dbId: number, data: { name?, style?, description? }): Update specified fields. Returns updated record.

17. deleteCategoryIfUnused(dbId: number): Check if any non-deleted link references this categoryId. If yes, throw error (LINK_CATEGORY_IN_USE). If no, delete the category.

**Tag CRUD:**

18. createTag(params: { name, color? }): Insert into link_tags. Default color='#666666'. Returns record.

19. findAllTags(): Query all link_tags. Returns array.

20. findTagById(dbId: number): Single tag by id. Returns tag or undefined.

21. findTagByName(name: string): Find tag by name. Returns tag or undefined. Used for import dedup.

22. updateTag(dbId: number, data: { name?, color? }): Update specified fields. Returns updated record.

23. deleteTagIfUnused(dbId: number): Check if any link_tag_pivot references this tagId. If yes, throw error (LINK_TAG_IN_USE). If no, delete the tag and its pivot entries.

**Link-Tag Pivot:**

24. setLinkTag(linkId: number, tagId: number | null): Delete existing pivot entries for this linkId. If tagId is not null, insert new pivot entry. Returns void.

25. getLinkTag(linkId: number): Query link_tag_pivot for this linkId, join with link_tags. Returns single tag or null. Per Go backend, each link has at most one tag in practice.

26. findPublicCategories(): Query link_categories that have at least one APPROVED, non-deleted link. Uses subquery or EXISTS. Returns array of categories.

Follow the pattern from CommentRepository for Drizzle query construction. Use eq(), and(), isNull(), like(), inArray(), sql, desc(), asc() from drizzle-orm. All link queries must filter out soft-deleted records (deletedAt is null) except where explicitly noted.
