    Implement methods:

    **Query Methods:**
    - getFilesByPath(uri: string, ownerId: number, options?): parse URI to get directory path. Find directory file record by walking parent/name tree. If directory not found, throw NotFoundException. List children with pagination. Return FileListResponse per RESEARCH Section 9: { files: FileItem[], parent: FileItem|null, pagination, props, context_hint, storage_policy, view }
    - getFileInfo(publicID: string): decode with EntityType.File. Find file by id. Find entity via primaryEntityId. Find storage policy. Return { file: FileItem, storagePolicy: PolicyInfo }
    - downloadFile(publicID: string): decode publicID, find file, find entity, get source path. Return { filePath, fileName, mimeType, size } for streaming by controller
    - getDownloadInfo(publicID: string): decode, find file+entity+policy. Return { type: 'local'|'cloud', url, storage_type, file_name, file_size } per RESEARCH Section 9. For local: type='local', no url
    - getPreviewURLs(publicID: string, ownerId: number): find the file's parent directory, list all image files in same directory, generate signed content URLs for each, return { urls: [{url, file_id, file_name, file_size}], initialIndex }
    - serveSignedContent(sign: string): parse signed token (publicID:expiresAt:signature). Verify HMAC-SHA256 signature and expiration. Decode publicID, find file+entity, return { filePath, mimeType } for streaming

    **Operation Methods:**
    - createEmptyFile(dto: { uri, type, err_on_conflict? }, ownerId: number): parse URI for path+fileName. findOrCreateParentPath. If err_on_conflict and file exists at same parentId+name, throw 409. Create entity record (for type=1 file: zero-size entity with policyId from default article_image policy). Create file record. Return FileItem
    - updateFileContent(publicID: string, uri: string, content: Buffer, ownerId: number): decode publicID, find file. Verify URI matches file path (detect move/rename conflicts -> 409). Write content to entity.source path. Update entity size/mimeType. Return { id, size, updated }
    - deleteItems(ids: string[], ownerId: number): decode each publicID. For each item: if directory, recursively delete all children (soft-delete files, delete entities, delete physical files). If file, soft-delete file record, delete entity record, delete physical file from disk. Return null
    - renameItem(id: string, newName: string, ownerId: number): decode publicID, find file. Check name conflict at same parentId (throw 409 with FILE_NAME_EXISTS). Update file.name. Return updated FileItem

    **Folder Methods:**
    - getFolderTree(publicID: string, ownerId: number): decode, find directory. Recursively list all descendant files. Generate signed download URLs for each file. Return { folder_name, files: [{url, relative_path, size}], expires } per RESEARCH Section 3
    - getFolderSize(publicID: string): decode, find directory. Recursively sum file sizes. Return { logicalSize, storageConsumption, fileCount } per RESEARCH Section 9 (camelCase field names)
    - updateFolderView(publicID: string, view: object): decode, find directory. Update file.viewConfig JSON. Return { view }
    - moveItems(sourceIDs: string[], destinationID: string, ownerId: number): decode all IDs. Verify all source files and destination folder exist and are owned by user. Check name conflicts at destination. Update parentId of source files to destination ID. Update childrenCount on old and new parent directories. Return null
    - copyItems(sourceIDs: string[], destinationID: string, ownerId: number): decode all IDs. For each source: copy physical file on disk (new entity record with same source content), create new file record with new ownerId/parentId. Original files unchanged. Return null

    **Helper Methods:**
    - findOrCreateParentPath(uriPath: string, ownerId: number, policyId: number): walk the path segments, create missing directory file records as needed. Return the parent directory file record
    - toFileItem(file: any, entity?: any): convert DB row to frontend FileItem format per RESEARCH Section 9: { id: Sqids-encoded, name, type, size, created_at, updated_at, path, owned, shared, permission, capability, primary_entity_public_id, ext, metadata, url, relative_path }
    - generateSignedContentUrl(publicID: string): HMAC-SHA256 sign with 15-min expiry, return full URL
