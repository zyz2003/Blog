<objective>
Build the ChatHistoryService — a framework-agnostic CRUD service for chat conversation persistence. It manages conversations (create, list) and messages (append, get, truncate) using Drizzle queries against the chat_conversations/chat_messages tables from Plan 02. Wire it into AiModule so Phase 18's ChatService can inject it. This is a migration-protected asset with zero AI library imports.

Purpose: AI-04 requires chat history storage. ChatHistoryService is the DB access layer for conversation persistence. Per D-353, truncateHistory hard-deletes old messages. The service is pure DB CRUD — no AI SDK, no LangChain — so it survives a framework switch unchanged. Phase 18's ChatService will call appendMessage in onFinish, getMessages to load context, and truncateHistory for compression.

Output: chat-history.service.ts with CRUD operations + unit tests, AiModule updated to register and export ChatHistoryService.
</objective>
