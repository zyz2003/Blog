**recordVisit(dto: VisitorLogRequestDto, request: Request): Promise<void>**

Per D-160 and D-164, implement the full RecordVisit flow:

1. Extract client IP from request headers: X-Forwarded-For (first IP before comma) -> X-Real-IP -> X-Original-Forwarded-For -> request.ip. Match Go getClientIP logic.

2. Get User-Agent from request header.

3. Generate visitorID = MD5(IP + UserAgent) as hex string. Use Node.js crypto.createHash('md5').update(ip + userAgent).digest('hex'). Matches Go generateVisitorID.

4. Request dedup check: call visitorDedupService.isDuplicateRequest(visitorID, dto.url_path). If duplicate, return immediately (no error, just skip). Matches Go requestDedup.LoadOrStore pattern.

5. Fire async processing (do NOT await): Use Promise-based async processing per D-160. The async processing function:
   a. Get today's date string in China timezone (YYYY-MM-DD)
   b. Check UV dedup: visitorDedupService.isUniqueVisitor(ip, todayDate). Returns isUnique boolean.
   c. Check PV dedup: visitorDedupService.isUniquePageView(ip, dto.url_path, todayDate). Returns isUniquePageView boolean.
   d. Parse UA: uaParserService.parse(userAgent) -> { browser, os, device }
   e. GeoIP lookup: await geoIPService.lookup(ip, referer) -> { city, province, country } or null
   f. Compute isBounce: dto.duration < 10 (matches Go: Duration < 10)
   g. Create visitor_logs record via repo.createLog with all fields
   h. Update visitor_stats via repo.upsertVisitorStats(todayDate, isUnique, isBounce) per D-166
   i. Update url_stats via repo.incrementUrlStats(dto.url_path, isUniquePageView, dto.duration, isBounce) per D-166
   Wrap entire async block in try-catch, log errors but never throw (fire-and-forget per D-160).

6. Return immediately (void). The async processing runs in background.

**getBasicStatistics(): Promise<VisitorStatisticsDto>**

Per D-168 and Go GetBasicStatistics logic:

1. Get today and yesterday dates in China timezone
2. Get month start (1st of current month) and year start (Jan 1 of current year)
3. Query visitor_stats for yesterday row -> extract yesterday_visitors, yesterday_views
4. Query visitor_stats for date range [monthStart, today] -> SUM uniqueVisitors, totalViews -> month_views
5. Query visitor_stats for date range [yearStart, today] -> SUM uniqueVisitors, totalViews -> year_views
6. Enrich today/yesterday from visitor_logs per Go enrichTodayYesterdayFromVisitorLogs:
   - today_views = repo.countTotalViews(today)
   - today_visitors = repo.countUniqueVisitors(today)
   - yesterday_views = repo.countTotalViews(yesterday)
   - yesterday_visitors = repo.countUniqueVisitors(yesterday)
7. Return VisitorStatisticsDto with all 6 fields

**getVisitorAnalytics(startDate?: string, endDate?: string): Promise<VisitorAnalyticsDto>**

Per D-167 and D-168:

1. Parse date params or default to last 7 days (China timezone, inclusive of today)
2. Call repo.getVisitorAnalytics(startDate, endDate)
3. For each dimension array, compute percentage: (count / totalInDimension * 100).toFixed(1) as string. Total = sum of all counts in that dimension.
4. Return VisitorAnalyticsDto with 6 dimension arrays

**getTopPages(limit?: number): Promise<UrlStatisticsDto[]>**

1. Clamp limit to [1, 100], default 10
2. Call repo.getTopPages(limit)
3. Map each row to UrlStatisticsDto, computing bounce_rate = totalViews > 0 ? (bounceCount / totalViews * 100).toFixed(1) : '0'
4. Return array

**getVisitorTrend(period?: string, days?: number): Promise<VisitorTrendDataDto>**

Per Go GetVisitorTrend logic (RESEARCH note: only daily data is returned):

1. Clamp days to [1, 365], default 30
2. Compute startDay = today - (days-1) days in China timezone
3. Iterate day-by-day from startDay to today:
   - For each day: visitors = repo.countUniqueVisitors(day), views = repo.countTotalViews(day)
   - Push { date: day formatted as ISO string, visitors, views } to daily array
4. Return VisitorTrendDataDto with daily array, weekly=[], monthly=[] (always empty per Go backend)

**getStatisticsSummary(): Promise<StatisticsSummaryDto>**

Per Go GetStatisticsSummary logic:

1. basic_stats = await this.getBasicStatistics()
2. top_pages = await this.getTopPages(10)
3. analytics = await this.getVisitorAnalytics() (default 7 days)
4. trend_data = await this.getVisitorTrend('daily', 30)
5. Return { basic_stats, top_pages, analytics, trend_data }

**getVisitorLogs(startDate?: string, endDate?: string, page?: number, pageSize?: number): Promise<VisitorLogsResponseDto>**

1. Parse date params or default to last 7 days
2. Clamp page to [1, inf], default 1; pageSize to [1, 200], default 20
3. Call repo.getVisitorLogsByTimeRange(startDate, endDate, page, pageSize)
4. Map each log to simplified DTO: { user_agent, ip_address, city, url_path, duration, created_at (RFC3339 format) }
5. Return { list, total, page, page_size }

Use China timezone utilities: create a helper function nowInChina() that returns new Date adjusted for UTC+8 offset. Create startOfDayInChina(date) and endOfDayInChina(date) helpers matching Go utils.NowInChina/StartOfDayInChina/EndOfDayInChina.
