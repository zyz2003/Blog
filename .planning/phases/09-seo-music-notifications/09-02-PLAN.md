<task type="auto">
  <name>Task 1: SitemapService with sitemap XML and robots.txt generation</name>
  <files>server/src/sitemap/sitemap.service.ts</files>
  <action>
Create SitemapService matching Go backend pkg/service/sitemap/service.go:

1. **Types** — Define at top of file:
   - ChangeFrequency enum/type: 'always' | 'hourly' | 'daily' | 'weekly' | 'monthly' | 'yearly' | 'never'
   - SitemapItem: { url: string, lastModified: Date | null, changeFreq: ChangeFrequency, priority: number }
   - URLSet (for XML output structure): { urls: Array<{loc, lastmod, changefreq, priority}> }

2. **generateSitemap()** — Per D-214, NO caching. Build URLSet containing:
   a. **Homepage**: `{baseURL}/`, priority 1.0, changeFreq 'daily', lastModified = new Date()
   b. **Public articles**: Call ArticleService.listPublic({ page: 1, pageSize: 1000 }) to get all public articles. For each article:
      - URL: use abbrlink if non-empty, else Sqids-encoded publicId. Format: `{baseURL}/posts/{abbrlink_or_publicId}`
      - Priority/frequency based on update time (updatedAt vs now):
        - <24h: priority 0.9, changeFreq 'daily'
        - <7d: priority 0.8, changeFreq 'weekly'
        - <30d: priority 0.7, changeFreq 'monthly'
        - else: priority 0.6, changeFreq 'yearly'
      - lastModified: article.updatedAt in ISO 8601 format (toISOString())
   c. **Published pages**: Call PageService to get published pages. For each page:
      - URL: `{baseURL}/{pagePath}` — strip leading `/` from pagePath to avoid double slashes
      - priority 0.5, changeFreq 'monthly'
      - lastModified: page.updatedAt
   d. **Link page**: `{baseURL}/link`, priority 0.6, changeFreq 'weekly'
   e. **Common pages**: `/archives` (0.7/daily), `/categories` (0.6/weekly), `/tags` (0.6/weekly), `/about` (0.5/monthly)

3. **generateXML(urlSet: URLSet)** — Per D-216, manual string building (consistent with RSS module approach):
   - XML declaration: `<?xml version="1.0" encoding="UTF-8"?>`
   - urlset root: `<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">`
   - Each URL: `<url><loc>{loc}</loc><lastmod>{lastmod}</lastmod><changefreq>{changefreq}</changefreq><priority>{priority.toFixed(1)}</priority></url>`
   - All text content escaped with xmlEscape() (reuse same 5-entity replacement as RSS)
   - Close: `</urlset>`

4. **generateRobots()** — Template string generation:
   - `User-agent: *`
   - `Allow: /`
   - `Disallow: /admin/`
   - `Sitemap: {baseURL}/sitemap.xml`
   - Read baseURL from SettingsService.get('SITE_URL'), fallback `https://blog.anheyu.com`, strip trailing slash

5. **getBaseURL()** — Read SITE_URL from SettingsService, fallback `https://blog.anheyu.com` (matching Go defaultBaseURL). Strip trailing slash.

6. **Constructor** — Inject: ArticleService, PageService, SettingsService. Use @Inject(forwardRef(() => ArticleService)) for ArticleService.

7. **Helper: getTimeDiffHours(date)** — Calculate hours between date and now for priority/frequency logic.

8. **Helper: xmlEscape(s)** — Same 5-entity replacement as RSS module (& first, then <, >, ", ').

Create SitemapController with 2 endpoints, both using @Res() to bypass global ResponseInterceptor:

1. **GET /sitemap.xml** — @Public() decorator
   - Call sitemapService.generateSitemap() to get URLSet
   - Call sitemapService.generateXML(urlSet) to get XML string
   - Set headers on @Res() res:
     - Content-Type: `text/xml; charset=utf-8`
     - Cache-Control: `public, max-age=3600`
     - Last-Modified: new Date().toUTCString()
   - res.send(xml)

2. **GET /robots.txt** — @Public() decorator
   - Call sitemapService.generateRobots() to get plain text
   - Set headers on @Res() res:
     - Content-Type: `text/plain; charset=utf-8`
     - Cache-Control: `public, max-age=86400` (24 hours, matching Go)
   - res.send(text)

Both endpoints use @Res() pattern from VersionController.getVersionString() — void return, res.send() directly.
