    Create all 12 schema files under server/src/database/schemas/. Each file imports sqliteTable, sqliteInteger, sqliteText from drizzle-orm/sqlite-core and sql from drizzle-orm. Per D-05, D-06, D-11.

    IMPORTANT type mapping rules (from RESEARCH.md Pitfall 6):
    - Go field.Uint -> sqliteInteger('column_name') -- unsigned integer
    - Go field.Int -> sqliteInteger('column_name')
    - Go field.Int64 -> sqliteInteger('column_name') -- SQLite INTEGER is 64-bit
    - Go field.String with MaxLen -> sqliteText('column_name')
    - Go field.Text -> sqliteText('column_name')
    - Go field.Time -> sqliteInteger('column_name', { mode: 'timestamp' }) -- stored as unix epoch
    - Go field.JSON -> sqliteText('column_name', { mode: 'json' })
    - Go field.Enum -> sqliteText('column_name') -- stored as text
    - Go field.Bool -> sqliteInteger('column_name', { mode: 'boolean' }) -- 0/1
    - Go field.Other with SchemaType SQLite: "text" -> sqliteText, with mode: 'json' if needed
    - SoftDeleteMixin -> add deletedAt: sqliteInteger('deleted_at', { mode: 'timestamp' })

    Common pattern for tables with SoftDeleteMixin: id (autoIncrement primary key), createdAt, updatedAt, deletedAt, then domain fields.
