### Task 1: Create BackupService

**What:** Implement BackupService matching Go backend's `backupService` with CreateBackup, ListBackups, RestoreBackup, DeleteBackup, CleanOldBackups.

**Files:**
- `server/src/backup/backup.service.ts`
- `server/src/backup/backup.module.ts`
- `server/src/backup/index.ts`

**How:**

1. Create `server/src/backup/backup.service.ts`:
   ```typescript
   @Injectable()
   export class BackupService {
     private readonly logger = new Logger(BackupService.name);
     private readonly backupDir: string;
     private maxBackupCount = 10;

     constructor(private readonly settingsService: SettingsService) {
       this.backupDir = path.join(process.cwd(), 'data', 'backups');
       fs.mkdirSync(this.backupDir, { recursive: true });
     }
   }
   ```

2. Implement methods (matching Go `backup_service.go`):

   - **createBackup(description: string, isAuto: boolean): Promise<BackupInfo>**
     - Call `this.settingsService.exportAll()` to get settings data
     - Generate filename: `settings_backup_{YYYYMMDD_HHMMSS}.json`
     - Write JSON file to `data/backups/`
     - Save metadata as `.meta.json` companion file
     - Auto-clean old backups if `maxBackupCount > 0`
     - Return `BackupInfo` object

   - **listBackups(): Promise<BackupInfo[]>**
     - Read `data/backups/` directory
     - Filter files matching `settings_backup_*.json` (exclude `.meta.json`)
     - Load metadata for each, fallback to file stat if no metadata
     - Sort by `createdAt` descending
     - Return array of `BackupInfo`

   - **restoreBackup(filename: string): Promise<void>**
     - Validate filename (prevent path traversal) — `validateBackupFilename()`
     - Check file exists
     - Create pre-restore backup: `this.createBackup('恢复前自动备份', true)`
     - Read backup file, parse JSON
     - Call `this.settingsService.importAll(data)`
     - Log success

   - **deleteBackup(filename: string): Promise<void>**
     - Validate filename
     - Delete backup file and companion `.meta.json`
     - Log deletion

   - **cleanOldBackups(keepCount: number): Promise<void>**
     - Validate keepCount (1-100)
     - List all backups, delete oldest beyond keepCount
     - Matches Go: `CleanOldBackups(ctx, keepCount)`

3. **validateBackupFilename(filename: string): void** (private):
   - Must not be empty
   - Must not contain `..`, `/`, `\`
   - Must match exact format: `settings_backup_YYYYMMDD_HHMMSS.json` (36 chars total)
   - Timestamp portion must be digits and underscores only
   - Matches Go: `validateBackupFilename()`

4. **BackupInfo interface:**
   ```typescript
   export interface BackupInfo {
     filename: string;
     size: number;
     created_at: string;  // ISO date string
     description: string;
     is_auto: boolean;
   }
   ```

5. Create `backup.module.ts`:
   ```typescript
   @Module({
     imports: [SettingsModule],
     providers: [BackupService],
     exports: [BackupService],
   })
   export class BackupModule {}
   ```

**Verify:** BackupService can create, list, restore, and delete backups; filename validation prevents path traversal.

**How:**

```
POST /api/config/backup/create  → CreateBackup
GET  /api/config/backup/list    → ListBackups
POST /api/config/backup/restore → RestoreBackup
POST /api/config/backup/delete  → DeleteBackup
POST /api/config/backup/clean   → CleanOldBackups
```

All routes require JWT + Admin auth (Go: `configBackupGroup.Use(r.mw.JWTAuth(), r.mw.AdminAuth())`).

1. **BackupController:**
   ```typescript

   ```

2. **Endpoints:**

   - `POST /api/config/backup/create`:
     - Body: `{ description?: string, is_auto?: boolean }` (optional)
     - Default description: "手动备份"
     - Default is_auto: false
     - Returns: `BackupInfo`
     - Matches Go: `CreateBackup(c *gin.Context)`

     - Body: `{ filename: string }` (required)
     - Returns: null with message "备份已删除"

   - `POST /api/config/backup/clean`:

     - Matches Go: `CleanOldBackups(c *gin.Context)`

3. **DTOs:**

   - `RestoreBackupRequestDto`: `filename` (string, required)
   - `DeleteBackupRequestDto`: `filename` (string, required)
   - `CleanBackupsRequestDto`: `keep_count` (number, required, min 1, max 100)

**Verify:** All 5 endpoints return correct response format `{ code, data, message }`; admin auth is enforced; filename validation prevents path traversal.

### Task 4: Wire ScheduledBackupJob to BackupService

**What:** Replace the ScheduledBackupJob stub from Plan 10-01 with the real BackupService call.

**Files:**
- `server/src/schedule/jobs/scheduled-backup.job.ts` — replace stub with real implementation

**How:**

1. Inject `BackupService` into `ScheduledBackupJob`
2. Replace stub with:
   ```typescript
   @Cron('0 4 * * *')
   async handleCron() {
     await this.scheduleService.runJob('ScheduledBackupJob', async () => {
       let lastErr: Error | null = null;
       let backup: BackupInfo | null = null;

       for (let attempt = 1; attempt <= 3; attempt++) {
         try {
           backup = await this.backupService.createBackup('定时自动备份', true);
           lastErr = null;
           break;
         } catch (err) {
           lastErr = err as Error;
           this.logger.warn(`备份失败 (第${attempt}次): ${lastErr.message}`);
           if (attempt < 3) {
             await new Promise(r => setTimeout(r, attempt * 10000)); // 10s, 20s, 30s
           }
         }
       }

       if (lastErr && !backup) {
         throw lastErr;
       }

       if (backup) {
         this.logger.log(`定时备份成功: ${backup.filename} (${backup.size} bytes)`);
       }
     });
   }
   ```
   Matches Go: retry 3 times with linear backoff (10s, 20s, 30s). **5-minute timeout wraps the entire retry loop** (matches Go: `context.WithTimeout` wraps all 3 attempts). Use `Promise.race([retryLoop(), timeout(300000)])`.

**Verify:** ScheduledBackupJob creates backup files at 4:00 AM with retry logic.

## Execution Notes

- **Go route mapping:** Go uses `/api/config/backup/create` (POST with JSON body). NestJS uses `@Controller('config/backup')` + `@Post('create')` which maps to the same path.
- **Backup file format:** `settings_backup_YYYYMMDD_HHMMSS.json` — exact same format as Go backend. Timestamp uses local time (not UTC) to match Go's `time.Now().Format("20060102_150405")`.
- **Metadata files:** `.meta.json` companion files store BackupInfo. This matches Go's `saveMetadata/loadMetadata` pattern.
- **Pre-restore backup:** RestoreBackup creates a backup of current config before restoring. This matches Go: `_, _ = s.CreateBackup(ctx, "恢复前自动备份", true)`.
- **SettingsService.autoBackup()** can be removed since BackupService now handles this properly.
