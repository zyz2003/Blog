<objective>
Implement the RSS module with 3 endpoints (GET /rss.xml, /feed.xml, /atom.xml) that return valid RSS 2.0 XML feeds. The feed contains the 20 most recent public articles, cached for 1 hour in memory. XML output bypasses the global ResponseInterceptor via @Res() decorator. Content-Type switches based on request path per Go backend behavior.

Purpose: RSS feeds allow visitors and RSS readers to subscribe to blog updates. Must match Go backend XML format exactly for RSS reader compatibility.
Output: RssService, RssController, RssModule with full RSS 2.0 XML generation and caching.
</objective>

<task type="auto">
  <name>Task 1: RssService with feed generation, XML building, and caching</name>
  <files>server/src/rss/rss.service.ts</files>
  <action>
Create RssService with the following methods, matching Go backend pkg/service/rss/service.go exactly:

1. **Types** — Define RSSFeed, RSSItem, RSSOptions interfaces at the top of the file:
   - RSSItem: { title, link, description, pubDate, guid, author, categories: string[] }
   - RSSFeed: { title, link, description, language, pubDate, lastBuildDate, items: RSSItem[] }
   - RSSOptions: { itemCount: number, baseURL: string, buildTime: Date }

2. **generateFeed(options: RSSOptions)** — Per D-213, check MemoryCache for key `rss:feed:latest` (TTL 3600000ms). On cache miss:
   - Read site title from SettingsService.get('APP_NAME'), default 'Anheyu Blog'
   - Read site description from SettingsService.get('SITE_DESCRIPTION'), default ''
   - Call ArticleService.listPublic({ page: 1, pageSize: options.itemCount }) to get 20 latest public articles
   - Build RSSFeed object: title, link (options.baseURL), description, language 'zh-CN', pubDate (RFC 1123 format of buildTime), lastBuildDate (same), items array
   - For each article, call buildRSSItem(article, options.baseURL)
   - Store RSSFeed in cache with key `rss:feed:latest`, TTL 3600000ms
   - Return RSSFeed

3. **buildRSSItem(article, baseURL)** — Per Go buildRSSItem:
   - title: article.title
   - link: `{baseURL}/posts/{article.publicId}` — use abbrlink if available, else Sqids-encoded publicId
   - guid: same as link
   - pubDate: RFC 1123 format of article.createdAt (use toUTCString() which produces RFC 1123)
   - description: call getArticleDescription(article)
   - author: article.copyrightAuthor or empty string
   - categories: from article.postCategories (name) + article.postTags (name), flattened

4. **getArticleDescription(article)** — Per Go getArticleDescription:
   - Priority 1: article.summaries[0] if non-empty string
   - Priority 2: strip HTML from article.contentHtml, truncate to 200 characters (UTF-8 rune-aware using Array.from())
   - Priority 3: truncate article.contentMd to 200 characters
   - Priority 4: empty string
   - For HTML stripping, use a simple regex: `text.replace(/<[^>]*>/g, '')` — isomorphic-dompurify is available but regex is sufficient for RSS descriptions

5. **generateXML(feed: RSSFeed)** — Per D-216, manual string building matching Go GenerateXML exactly:
   - XML declaration: `<?xml version="1.0" encoding="UTF-8"?>`
   - RSS root with namespaces: `<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom" xmlns:content="http://purl.org/rss/1.0/modules/content/">`
   - Channel element with title, link, description, language, lastBuildDate
   - atom:link self-reference: `<atom:link href="{feed.link}/rss.xml" rel="self" type="application/rss+xml"/>`
   - Each item: title, link, guid (isPermaLink="true"), pubDate, description, author, category elements
   - All text content must pass through xmlEscape()

6. **xmlEscape(s: string)** — Per Go xmlEscape, 5 replacements in order (& MUST be first):
   - `&` → `&amp;` (first to avoid double-escaping)
   - `<` → `&lt;`
   - `>` → `&gt;`
   - `"` → `&quot;`
   - `'` → `&apos;`

7. **invalidateCache()** — Delete key `rss:feed:latest` from MemoryCache. Per D-215, this will be called from ArticleService create/update/delete.

8. **getBaseURL(req)** — Read SITE_URL from SettingsService. If empty, construct from request: `req.protocol + '://' + req.get('host')`. Strip trailing slash.

9. **Constructor** — Inject: ArticleService, SettingsService, MemoryCache. Use @Inject(forwardRef(() => ArticleService)) for ArticleService to handle circular dependency (ArticleService will also inject RssService in Plan 07).

10. **Date formatting** — Use `new Date().toUTCString()` which produces RFC 1123 format like "Sun, 13 Jul 2026 12:00:00 GMT". For timezone offset format matching Go's RFC1123Z, append the offset: if the date has no timezone offset info, use `+0000`. The exact format: `date.toUTCString().replace('GMT', '+0000')`.

Add RSS error codes to error-codes.ts:
- RSS_GENERATE_GENERATE_FAILED: 'RSS生成失败'

<task type="auto">
  <name>Task 2: RssController with 3 XML endpoints and RssModule wiring</name>
  <files>server/src/rss/rss.controller.ts, server/src/rss/rss.module.ts</files>
  <action>
Create RssController with 3 endpoints, all using @Res() to bypass global ResponseInterceptor (per D-216, matching Go handler pattern):

1. **GET /rss.xml** — @Public() decorator (no auth required)
   - Get baseURL from rssService.getBaseURL(req)
   - Call rssService.generateFeed({ itemCount: 20, baseURL, buildTime: new Date() })
   - Call rssService.generateXML(feed)
   - Set headers on @Res() res object:
     - Content-Type: `application/rss+xml; charset=utf-8`
     - Cache-Control: `public, max-age=3600`
     - X-Content-Type-Options: `nosniff`
     - Last-Modified: new Date().toUTCString()
   - res.send(xml)
   - On error: set Content-Type to `text/plain; charset=utf-8`, status 500, send error message

2. **GET /feed.xml** — Same logic as /rss.xml, same Content-Type `application/rss+xml; charset=utf-8`

3. **GET /atom.xml** — Same logic as /rss.xml, but Content-Type is `application/atom+xml; charset=utf-8`

All three endpoints return the SAME RSS 2.0 XML content. Only Content-Type differs based on path.

IMPORTANT: Use @Res() decorator pattern from server/src/version/version.controller.ts getVersionString() method. The controller method signature must be `@Res() res: Response` and must NOT return a value (void return, use res.send() directly).

4. **RssModule** — Update the empty placeholder:
   - imports: [DatabaseModule, CommonModule, SettingsModule, forwardRef(() => ArticleModule)]
   - controllers: [RssController]
   - providers: [RssService]
   - exports: [RssService] — so ArticleService can inject it for cache invalidation
   - ArticleModule import uses forwardRef() to handle circular dependency (RssService needs ArticleService, ArticleService will need RssService)
