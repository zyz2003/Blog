Create the notifications table schema, repository, and all DTOs:

**notification.schema.ts** — Per D-217, create new notifications table:
- id: integer PK auto-increment
- userId: integer not null, references users.id
- notificationTypeId: integer not null, references notification_types.id
- title: text not null
- content: text (nullable)
- isRead: integer boolean not null default false
- createdAt: integer timestamp not null default unixepoch()
- readAt: integer timestamp (nullable)
- Indexes: idx_notifications_user_id on userId, idx_notifications_user_unread on (userId, isRead), idx_notifications_type_id on notificationTypeId

**schemas/index.ts** — Add `export * from './notification.schema';` at the end of the file.

**notification.repository.ts** — Drizzle query methods:
1. Constructor: @Inject(DRIZZLE) private readonly db
2. **findNotificationTypes()** — Select all from notificationTypes table
3. **findNotificationTypeByCode(code: string)** — Select from notificationTypes where code = code
4. **createNotificationType(data)** — Insert into notificationTypes, return created record
5. **updateNotificationType(id: number, data)** — Update notificationTypes where id = id
6. **findUserNotificationConfigs(userId: number)** — Select from userNotificationConfigs where userId = userId, with join to notificationTypes for nested type info
7. **findUserNotificationConfig(userId: number, typeId: number)** — Select from userNotificationConfigs where userId and notificationTypeId
8. **createUserNotificationConfig(data)** — Insert into userNotificationConfigs
9. **updateUserNotificationConfig(id: number, data)** — Update userNotificationConfigs where id = id
10. **findNotifications(userId: number, options: { page, pageSize, isRead?: boolean })** — Select from notifications where userId, optional isRead filter, order by createdAt desc, with pagination (offset/limit). Return { list, total }.
11. **findNotificationById(id: number, userId: number)** — Select from notifications where id and userId (user-scoped for security)
12. **markNotificationAsRead(id: number)** — Update notifications set isRead=true, readAt=now where id = id
13. **markAllNotificationsAsRead(userId: number)** — Update notifications set isRead=true, readAt=now where userId and isRead=false
14. **countUnreadNotifications(userId: number)** — Select count(*) from notifications where userId and isRead=false
15. **createNotification(data: { userId, notificationTypeId, title, content? })** — Insert into notifications, return created record

**DTOs:**

notification-type.dto.ts:
- NotificationTypeResponseDto: { id, code, name, description, category, isActive, defaultEnabled, supportedChannels, createdAt, updatedAt }

user-notification-config.dto.ts:

Create NotificationController with 7 endpoints and wire NotificationModule:

**NotificationController** — Split into two controller sections within the same file for clarity:

Admin endpoints (JWT + AdminGuard):
1. **GET /api/notification/types** — @UseGuards(JwtAuthGuard, AdminGuard)
   - Call notificationService.listNotificationTypes()
   - Return array of NotificationTypeResponseDto

User endpoints (JWT only):
2. **GET /api/user/notification-settings** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user (decode publicId to dbId via decodePublicID)
   - Call notificationService.getUserNotificationSettings(userId)
   - Return SimpleNotificationSettingsResponseDto

3. **PUT /api/user/notification-settings** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user
   - Accept @Body() dto: UpdateSimpleNotificationSettingsDto
   - Call notificationService.updateUserNotificationSettings(userId, dto)
   - Return SimpleNotificationSettingsResponseDto

4. **GET /api/user/notification-configs** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user
   - Call notificationService.getUserNotificationConfigs(userId)
   - Return array of UserNotificationConfigResponseDto

5. **GET /api/user/notifications** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user
   - Accept @Query() query: { page?, pageSize?, isRead? }
   - Call notificationService.listNotifications(userId, { page, pageSize, isRead })
   - Return NotificationListResponseDto

6. **PUT /api/user/notifications/:id/read** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user
   - Accept @Param('id') id: number
   - Call notificationService.markNotificationAsRead(id, userId)
   - Return null (data: null)

7. **PUT /api/user/notifications/read-all** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user
   - Call notificationService.markAllNotificationsAsRead(userId)
   - Return null (data: null)

8. **GET /api/user/notifications/unread-count** — @UseGuards(JwtAuthGuard)
   - Extract userId from req.user
   - Call notificationService.getUnreadCount(userId)
   - Return UnreadCountResponseDto

Note: These endpoints do NOT use @Public() — they require JWT authentication. The global JwtAuthGuard handles this, but explicit @UseGuards(JwtAuthGuard) is added for the admin endpoint to combine with AdminGuard.

- providers: [NotificationService, NotificationRepository]
- exports: [NotificationService] — so CommentService can inject it for notification creation in Plan 07
